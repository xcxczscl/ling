## 这是什么

【待补】用三段以内的白话说明：

- 它解决什么问题；
- 谁会用、在什么场景下用；
- 它和同类东西的区别在哪。

目标与非目标：

| 类别 | 内容 |
|---|---|
| 目标 | 【待补】 |
| 非目标 | 【待补】明确不做什么，避免范围蔓延 |
