# MVP 界定

> 状态：草案 v0.1 ｜ 范围：仅界定 MVP，不替代 `01-总体设计`
> 本文回答：**第一版做什么、不做什么、做到什么程度算完成。**
> 语义层（词条/版本/标签/关系）的存储关系按 `01`/`02` 执行，**MVP 不实现，本文不展开**。

---

## 1. MVP 一句话

**在 Windows 上，扫描本机磁盘和接上的移动存储，建立持久索引，找出重复文件，只输出清单，不动任何文件。**

---

## 2. 范围

### 2.1 做

| 维度 | MVP 范围 |
|---|---|
| 平台 | Windows 电脑 |
| 对象 | 本机磁盘 + 当前接上的移动存储（U 盘 / 移动硬盘 / SD 卡） |
| 设备在线方式 | 移动存储**先后插上**分别扫描，索引持久化，之后可跨盘查询 |
| 功能 | 扫描 → 建索引 → 查重 → 导出重复组清单 |
| 输出 | 命令行结果 + 可导出的 JSON/表格 |
| 文件操作 | **只读**。不删除、不移动、不硬链接、不压缩 |

### 2.2 不做

| 不做的事 | 归属 |
|---|---|
| 跨网络（第二台电脑、NAS、Android） | MVP 之后 |
| 云盘 | 明确排除 |
| 语义层：词条 / 版本 / 标签 / 关系 | 按 `01`/`02` 保留，MVP 不实现 |
| 安全清理（删除 / 硬链接 / 归纳） | MVP 之后 |
| 按需同步、备份、AI | MVP 之后 |
| 图形界面 | 非必需；命令行 + 数据库查询即可，界面后续加 |

---

## 3. MVP 用到的概念（仅物理层）

| 概念 | 定义 | 说明 |
|---|---|---|
| **设备 Device** | 一台电脑或一块存储的登记 | 移动硬盘也算设备 |
| **位置 Location** | 设备上的一个根目录，是扫描的入口 | 如 `D:\media`、`E:\` |
| **内容 Content** | 一段数据本身，用 BLAKE3 指纹标识，内容相同即同一份数据 | 内容登记后不变 |
| **放置 Placement** | “某段内容实际在哪个位置的哪个路径”这条记录 | 同一内容可以有多条放置 |

> 语义层的“版本”不进入 MVP。MVP 回答的是“哪些数据重复、副本在哪”，不是“这属于哪部作品”。

---

## 4. MVP 数据模型（最小表）

只建 4 张表，字段够用即止：

**device**
`id`、`name`、`platform`（固定 `windows`）、`created`

**location**
`id`、`device_id`、`root_path`、`label`、`state`（`online` / `offline`）、`created`

**content**
`blake3`（主键）、`size`、`created`

**placement**
`id`、`location_id`、`rel_path`、`content_id`、`size`、`mtime`、`state`（`online` / `missing`）、`first_seen`

唯一约束：`(location_id, rel_path)`。

> 不建 `entry` / `version` / `tag` / `connection` / `instance` / `pool` / `op` / `peer` 等表。这些属于主设计，MVP 不碰。

---

## 5. MVP 流程

### 5.1 添加位置
用户指定一个目录，登记为 location，设备记为当前 Windows 机器。

### 5.2 扫描
1. 遍历目录，记录每个文件的 `rel_path`、`size`、`mtime`。
2. **分层哈希**，避免全盘读：
   - 第一级：按文件大小分组；大小唯一的文件直接排除。
   - 第二级：对同大小组计算 BLAKE3。
3. 批量写入 SQLite（`content` 一条、`placement` 一条）。
4. 增量重扫：路径、大小、mtime 都没变的文件，跳过重新哈希。

### 5.3 查重
按 `content.blake3` 分组，输出放置数 ≥ 2 的组：
- 每组：内容指纹、大小、副本数、每条放置的位置与路径。
- 可导出 JSON / 表格，供人工核对。

### 5.4 跨盘查询
先后扫描多块移动存储后，同一数据库内直接按内容指纹查出跨盘重复组。设备拔掉不影响已建索引。

## 6. 验收标准（MVP 完成判据）

| # | 验收项 | 判定方法 |
|---|---|---|
| 1 | 能添加一个本机目录并完成扫描 | 命令执行后统计文件数与总字节 |
| 2 | 能对同大小文件算出 BLAKE3 并识别完全重复 | 构造已知重复文件，结果与预期一致 |
| 3 | 先后扫描两块移动存储，能查出跨盘重复组 | 同一文件分别放在两块盘，查重结果包含两条放置 |
| 4 | 拔掉移动存储后，索引仍可查询 | 断开后重查，记录仍在 |
| 5 | 扫描过程不修改任何文件 | 扫描前后文件哈希/修改时间不变 |
| 6 | 结果可导出，供人工核对 | 导出 JSON/表格，字段完整 |
