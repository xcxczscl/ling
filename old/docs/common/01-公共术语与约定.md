# 01 公共术语与约定

> 适用范围：ling、resources-manager 与 player（占位项目）的全部文档与代码。
> 各项目**专属**的术语（如"词条""放置"、"上下文""可逆效应"）写在各自项目的术语章节，本文只收共用部分。

---

## 1. 共用术语表

> 格式：**白话定义 + 例子 + 它不是什么**。

### 1.1 与插件体系相关（ling 为主，resources-manager 也会用到）

| 术语 | 白话定义 | 例子 | 它不是什么 |
|---|---|---|---|
| **宿主（Host）** | 那个"大程序"，负责加载插件、在插件之间传递调用与事件。它自己不含任何功能 | ling 是宿主 | 不是操作系统，也不是服务器 |
| **插件（Plugin）** | 一个可以被宿主加载/卸载的功能模块，编译成独立产物 | 资源管理功能是一个插件；记账功能是另一个插件 | 不是脚本、不是外挂。Rust 插件编译成动态链接库，其他语言插件编译成独立小进程 |
| **能力（Capability）** | 插件在清单里声明自己需要的权限，宿主运行时检查，没声明就拒绝 | 资源管理插件声明"读写文件""访问局域网" | 不是操作系统账号权限，是插件级门禁 |
| **调用路由（Broker）** | 宿主里负责"把 A 插件的请求转发给 B 插件"的部件 | 记账插件调资源管理插件查文件指纹，由调用路由中转 | 不是网络服务；同进程插件之间是直接函数调用 |
| **事件总线（Event Bus）** | 宿主里的广播系统。一个插件广播，所有订阅了的插件都能收到 | 扫描完成后广播"扫描结束"，界面插件据此刷新 | 不是消息队列服务器，不落盘、不重投 |
| **作业（Job）** | 一个耗时任务的登记：有进度、有状态、可查询、可取消 | 扫描 10 TB 是一个作业，界面上能看到百分比 | 不是命令。命令是触发动作，作业是被登记的长任务 |
| **侧车（Sidecar）** | 非 Rust 插件的运行方式：一个独立的小进程，通过本机套接字与宿主通话 | 用 Python 写的刮削插件，编译/打包成一个可执行文件常驻 | 不是后台服务，不是容器；只服务于一个插件 |
| **内置插件（Builtin Plugin）** | 随宿主一起发行、放在 `ling/builtin-plugins/` 目录的插件；与普通插件遵守同一规范，可卸载 | 首次启动默认安装三件套：core-ui / core-settings / core-plugin-manager | 不是内核的一部分——卸掉宿主照样能跑；"内置"只表示发行方式，不给特权 |
| **管理端口** | 宿主自带的仅本机可访问的端口，供 `ling` 命令行连接 | `ling plugins` 通过管理端口查询插件状态 | 不是插件的业务端口；界面壳插件另有自己的端口 |

### 1.2 与论文机制相关（ling 专属概念的共用简表，详细解释见 ling/docs）

| 术语 | 白话定义 | 例子 | 它不是什么 |
|---|---|---|---|
| **上下文（Context）** | 插件与外界交互的唯一通道。插件的任何改动（注册方法、订阅事件、写配置）都必须经过它，因此宿主能记下每一笔 | 插件想注册一个接口方法，必须调用上下文的注册函数 | 不是"环境变量"，也不是配置文件；是运行时的一个受控对象 |
| **效应（Effect）** | 插件对共享环境做出的**修改** | 注册了一个接口方法 = 产生了一条效应 | 不是"副作用"这个编程俗语的泛指，是被登记在册的具体修改 |
| **可逆效应（Revertible Effect）** | 每条修改都必须**连同撤销方法**一起交给宿主保管 | 注册方法时，同时交出"注销这个方法"的函数 | 不是自动撤销魔法；是要求插件作者在注册时一并提供撤销手段 |
| **协效应（Coeffect）** | 插件对环境的**需求声明**：我需要什么才能工作 | 插件声明"需要 core-ui 插件的 1.x 版本界面贡献接口" | 不是依赖包管理器里的依赖；是运行时可动态重判的需求 |
| **依赖图（Dependency Graph）** | 所有插件的需求声明连成的有向图，宿主靠它决定谁该激活 | resources-manager 需要 core-ui → 图上有一条边 | 不是编译期的模块导入图 |
| **配置调和（Reconciliation）** | 环境变化后，宿主重新推导"该激活谁、该停用谁"，逐步收敛的过程 | 装上新插件后，宿主算出有 2 个插件可激活、1 个需停用，然后执行 | 不是"重启一遍"；是增量、可中途取消的计算 |
| **热更新（HMR，Hot Module Replacement）** | 更换某个插件的新版本时，只重载那一个，宿主与其他插件不停机 | 开发时改了 resources-manager 代码，执行 `ling reload resources-manager` 秒级生效 | 不是自动保存；不是整程序重启 |

### 1.3 与数据/文件相关（resources-manager 为主，ling 偶尔引用）

| 术语 | 白话定义 | 例子 | 它不是什么 |
|---|---|---|---|
| **哈希（Hash）/ 指纹** | 把任意数据算成一串固定长度字符，用于唯一标识数据。本项目用 BLAKE3 算法 | 1 GB 视频算出一串 64 字符指纹 | 不是加密；哈希不可逆，算不出原数据 |
| **内容寻址（Content-Addressable）** | 用数据内容算出的哈希来命名数据，而不是用文件名 | 同一部电影文件名不同，只要内容相同，哈希就相同，系统即知是重复 | 不是一种数据库，是一种命名方式 |
| **硬链接（Hardlink）** | 让同一份磁盘数据在同盘上拥有两个路径，两者完全等价、不占双份空间 | 去重后把 `/a/电影.mkv` 与 `/b/电影.mkv` 合并成硬链接 | 不是快捷方式（快捷方式是另一个文件指向原文件） |
| **回环地址（Loopback）** | 本机内部网络地址 `127.0.0.1`，只有本机能访问 | 网页界面通过 `http://127.0.0.1:7910` 访问 | 不是局域网地址；局域网地址其他设备也能连 |
| **墓碑（Tombstone）** | "这条登记已被删除"的标记，不是立刻真删 | 删除一份重复文件先立墓碑 | 不是备份 |
| **宽限期（Grace Period）** | 墓碑立起后要等满 30 天才允许真正清除数据 | 长期离线的设备回连前不会误删 | 不是同步周期 |
| **刮削（Scraping）** | 从公开资料站（TMDB、豆瓣等）抓取作品的官方信息补进自己的词条 | 用"深空旅人 2007"查到 TMDB 条目，拉回简介和封面 | 不是搜索引擎；结果会结构化写入自己的数据库 |

## 2. 命名约定（两项目统一）

### 2.1 代码与标识符

| 对象 | 约定 | 例子 |
|---|---|---|
| ling 代码包 | `ling-` 前缀 | `ling-kernel`、`ling-sdk` |
| resources-manager 代码包 | `rm-` 前缀 | `rm-catalog`、`rm-scan` |
| 插件编号 | 小写字母、数字、短横线，全局唯一 | `core-ui`、`resources-manager` |
| 数据库表名 | 单数蛇形 | `placement`、`version_file` |
| 接口方法 | `领域.动作` | `scan.start`、`kernel.plugins` |
| 事件主题 | `插件.对象.动作` | `resources-manager.job.progress` |

### 2.2 命令行

| 命令 | 归属 | 作用 |
|---|---|---|
| `ling` | 宿主 | 管理宿主本体与插件（`serve` / `plugins` / `reload` / `logs`） |
| `rmgr` | resources-manager | 资源管理业务（`scan` / `dup` / `sync` …） |

### 2.3 端口与文件

| 对象 | 约定 |
|---|---|
| ling 管理端口 | 默认 `7900`，被占用自动顺延 |
| 界面壳插件（core-ui）网页端口 | 默认 `7910`，被占用自动顺延 |
| 实际端口存放 | ling 数据根目录下 `ling/registry.json`（各程序启动时读取） |
| 会话口令 | `ling/session.json`，权限 0600（仅本人可读） |
| 内核配置键值 | `ling/config.json`（`context.set_config` 的存储，内核拥有；见 ling/docs/02 §3.3） |
| 插件安装目录 | `ling/plugins/<插件编号>/` |
| 插件状态数据 | `ling/plugins/<插件编号>/data/`（插件自己管理的持久文件放这里） |

**ling 数据根目录（`ling/` 所在位置）按操作系统**：

| 系统 | 默认位置 | 说明 |
|---|---|---|
| Linux | `$XDG_DATA_HOME/ling/`（缺省 `~/.local/share/ling/`） | 遵循 XDG 约定 |
| Windows | `%APPDATA%\ling\`（即 `C:\Users\<用户>\AppData\Roaming\ling\`） | —— |
| macOS | `~/Library/Application Support/ling/` | 预留（第一轮不交付，路径先定） |
| 安卓 | 应用私有目录（`Context.getFilesDir()/ling/`） | 壳应用注入；SAF 授权目录另走位置登记 |
| 覆盖方式 | 环境变量 `LING_HOME` 显式指定（测试、便携场景） | 设置后上述默认全部失效 |

### 2.4 版本号

- 项目版本：语义化 `主.次.修`（如 `0.1.0`）。
- 宿主接口版本：单独一套 `1.x`，写在插件清单的 `api` 字段；宿主不兼容时拒绝加载该插件并说明原因。
