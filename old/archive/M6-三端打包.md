## 范围（对照 `docs/01` §8 / §12.1）

- **发行包组装**：`scripts/package.sh` 把 ling 宿主 + 五内置插件 + resources-manager + rmgr + 服务脚本组装成 `dist/release/` 与 `tar.gz`。
- **Linux 常驻**：systemd 用户级服务单元（`Restart=on-failure`、linger 开机自启）。
- **Windows 常驻**：服务安装/卸载 PowerShell 脚本（NSSM 优先，sc.exe 回退）。
- **rm-fs 跨平台补齐**：
  - Windows：`\\?\` 长路径前缀 + UNC 处理 + `file_index` inode（01 §13 风险 #10）；
  - 安卓：`SafRegistry` 授权清单接口占位（01 §13 风险 #1、§8.3），编译就绪；
  - `file_meta` 跨平台 inode（unix/windows/其他）。
- **交叉编译就绪**：`.cargo/config.toml` 注释写明 Windows（mingw）/Android（cargo-ndk）路径；`package.sh` 支持 `TARGET=` 切换。

## 关键决策 / 偏差登记（docs/01 附录 B #15、docs/04 §3 M6）

1. **壳层归属**：窗口壳（Tauri）/安卓壳归 ling `apps/`（04 §1 原约定）；本仓库交付**组装发行物**与服务注册，不产 APK/Tauri 安装包。
2. **交叉编译未预装**：mingw/cargo-ndk 未随环境；`TARGET=` + `.cargo/config.toml` 注释冻结路径，工具链具备即用。
3. **安卓 SafRegistry 接口占位**：GrantedDir/grant/revoke/is_granted 冻结；真实 SAF 绑定依赖 NDK 与壳层。
4. **Windows 长路径仅 windows 目标编译**：Linux CI 不跑 `to_long_path`；单测用 `#[cfg(windows)]` 保护。
5. **ling 补 `.cargo/config.toml`**：musl 主机打 cdylib 需要 `-crt-static` 关闭；否则 package.sh 构建 ling 插件失败。
6. **发行包冒烟**：`location add <dir>` → `scan <loc_id>`（参数是 location id 非路径）→ `dup list` 出重复组；已对 `dist/release` 实测。

## 复验命令

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cd resources-manager
cargo test --workspace -- --test-threads=1
cargo test -p rm-plugin --test m6_acceptance -- --test-threads=1
./scripts/package.sh
# 冒烟（产物路径按实际）：
OUT=dist/release
SMOKE=$(mktemp -d); mkdir -p "$SMOKE/data" "$SMOKE/scan"; echo hi > "$SMOKE/scan/a.txt"
"$OUT/bin/rmgr" --standalone --db "$SMOKE/data/catalog.db" location add "$SMOKE/scan" --label s
LOC=$("$OUT/bin/rmgr" --standalone --db "$SMOKE/data/catalog.db" location list | cut -f1)
"$OUT/bin/rmgr" --standalone --db "$SMOKE/data/catalog.db" scan "$LOC"
"$OUT/bin/rmgr" --standalone --db "$SMOKE/data/catalog.db" dup list
```
