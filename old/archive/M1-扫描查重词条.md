## 关键决策 / 偏差登记

1. **无 node/vite** → 页面 `include_str!` 静态 HTML + `core-ui.ui.contribute`（附录 B #10）。
2. **CLI M1 仅 standalone**；core-ui `/rpc` 网关集成 M2。
3. **copy_count** 与 placement 增删同事务维护（`docs/02` §8.3 不变式）。
4. **安全删除**：唯一在线未校验副本 / pinned / 离线冷副本 → 拦截（CLI 退出码 3）。
5. **ensure_tag** 自动创建缺失 tag_domain（FK）。
6. **ClassifyRule.match** Rust 字段名 `match_spec` + `#[serde(rename="match")]`（关键字）。
