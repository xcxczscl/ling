## 范围（对照 `docs/01` §9 P6）

- **player.db（§5.11，落 `store.rs`）**：按 schema 照表建 `session`（主键 `content_id`：position/volume/subtitle_track/audio_track/playback_rate/updated_at/device_id）+ `setting`（key/value）；开库即 **WAL + `busy_timeout 5s` + `CREATE TABLE IF NOT EXISTS`**，自动建父目录。`device_id` = setting 表 get-or-create（getrandom 8 字节 hex，跨重开稳定，P7 对等同步沿用）。**降级语义**：开库失败 → `PlayerState.store=None` 纯内存（不阻塞装载/播放）；单次读写失败 best-effort 忽略——持久化是增强面，绝不打断播放主链。
- **数据根（#19/#64 落地）**：`data_root(ctx)` = `PLAYER_DATA_DIR` 非空覆盖、否则 `ctx.data_dir()`；**player.db 与 P5 `sandbox/` 同源**（UI 资源页仍走 `ctx.data_dir()`，资源 vs 数据分口径）。
- **写穿钩子**：pause/resume/seek/set_volume/set_subtitle 成功后 upsert；`player.stop` **先落库再停**（停后 time-pos 抓不到）；`player.playback.progress`（≈1s 心跳）/`paused` 事件；`player.playback.finished` 事件与停机 flush（**Finished 相自动归 0**，播完下次从头看）；**Failed 不落**（瞬时错误会把 time-pos 打成 0，写下去反抹有效进度）。停机 flush 走 `deactivate()` 与 `on_deactivate` **双入口**，且均先于 `sessions.clear()` 拆后端。查看器会话与无 `content_id` 会话不入表；`audio_track`/`playback_rate` 按 schema 预置但控制面未落（不回放，列留后续）。
- **播放侧恢复**：`backend.load_at(url, start_sec)` = `loadfile` 后轮询 `duration>0`（解复用就绪，≤3s；seek 与 `sid` 回放都要求已装载）再绝对定位；`player.play` 读 `content_id` 已存快照 → `load_at` + best-effort 回放 `volume`/`subtitle_track`（内容变更轨位对不上不阻断）→ 响应增 **`resumed`**（`resume_position_sec > 0`）与 **`resume_position_sec`**（首播恒 `false/0.0`）。
- **输出选择态（#39 兑现）**：`player.outputs.set` 成功 → upsert `setting('outputs.selected')`；activate 读回经 `outputs::validate` 恢复，校验失败不恢复选择**但保留设置值**（下次插回即恢复）。
- **依赖（#65）**：`rusqlite = 0.32 (bundled)` 与 rm 同选型同版本（musl 容器无系统 sqlite，bundled 静态链接）。
- **验收口径（#68）**：e1–e3 均在**同一数据根 `shutdown` → 重 boot** 下断言真持久化（`Kernel::new(同一 root)` 反复 boot 实证非内存态）；resume 回显取 play 响应、进度取 `player.status` 直读 mpv property（同 #24 headless 惯例）。

## 关键决策与登记（附录 B）

- **#63 落地形态**：写穿钩子全清单；`stop` 先落库再停；Finished 自动归 0、Failed 不落；停机 flush 双入口先于拆后端；`load_at` 等装载再定位（seek/`sid` 均依赖已装载）；音量/字幕 best-effort 回放；play 响应 `resumed`/`resume_position_sec`；查看器/无 content_id 不入表；`audio_track`/`playback_rate` 列预置不回放。
- **#64 数据根**：`PLAYER_DATA_DIR` 从设计文字变代码消费点（#19 兑现）——`data_root` 统一 player.db 与 `sandbox/`；UI 资源仍走 `ctx.data_dir()`（资源 vs 数据分口径）。
- **#65 依赖**：rusqlite 0.32 bundled（workspace 不新增 crate 的约束针对 crate，依赖按设计登记可加；与 rm 同选型）。
- **#66 device_id**：setting 表 get-or-create（getrandom 8B hex），跨重开稳定（单测 t4）；P7 对等同步/接力作对端标识，届时消费（当前仅单测断言，`#[allow(dead_code)]`）。
- **#67 #39 兑现**：P2 曾登记「选择态 P6 起随设置持久化」——`outputs.set` 写 setting + activate 经 `validate` 恢复，校验失败保留设置值不覆盖。
- **#68 验收口径**：同数据根多 boot 三用例证真持久化；`Kernel::new` 反复 boot 本环境实证可行（静态单例/discovery 监听/mpv 实例均兼容）。
