## 范围（对照 `docs/01` §9 P0）

- **管道打通**：`resources-manager.stream.open`（Source，03 §2.6 冻结契约）→ libmpv 解码（Capability，事件泵 + ≥1s 进度节流 + keepaspect 比例）→ 本机屏幕/扬声器（Sink；headless 环境 `vo=null ao=null`，真实渲染留桌面端）。
- **控制面**：静态 HTML 控制页（播放/暂停/继续/seek/音量/状态轮询），经 core-ui `/rpc` 网关调 `player.*` 方法；`player.ui.page` 直出兜底。
- **方法/事件（§5.12）**：`player.play/pause/resume/seek/set_volume/stop/status/ui.page`；`player.playback.started|progress|paused|finished` 事件广播。
- **状态机（§5.11 内存态）**：`playing ⇄ paused → finished/stopped`；未知会话一律 P401；P0 会话不持久化（stop 即摘，player.db 留 P6）。
- **画面比例（§5.5）**：libmpv `keepaspect` + 可断言纯函数 `fit_rect/borders_of/fit`（scale=min 一次取，禁四边黑边），5 项单测守护。
- **前置（跨项目，已单独登记）**：rm 流交付契约补齐——`stream.rs` 回环 HTTP + 128-bit 内存态 token + Range/HEAD/206/416 + zstd 透明 + idle 600s 过期；`stream.open`/`get_local_path` 注册；端口 7913 忙退 7932–7951、永跳 7914/7915。

## 关键决策与变更登记

1. **流契约补齐定位**：rm `03` §2.6 冻结契约自 M3 起未实现（player P0 依赖）——按「补齐冻结契约」落地，03 文档一字未动；登记在 rm 01 附录 B 第 16 条。
2. **能力词表**：设计稿 `capabilities=["net"]` 不在 ling 词表（fs/network/ui/shell），实装 `["network"]`——player 01 附录 B #21。
3. **P100 新增**：参数/调用错误独立成码（P103 保持资产类型本义）——#22；e2e 实测 P100/P101/P401 分域。
4. **`player.play` 双入参**：主接口 `{content_id}`（browse 分页检索本机在线放置，rm 方法不改）+ 兼容 `{placement_id}`（browse 直出）——#23。
5. **headless 验收口径**：本环境无显示/音频 → `vo=null ao=null` 验解码/进度/暂停冻结/seek/phase 收束；比例靠 §5.5 纯函数单测 + keepaspect；真实渲染留桌面端手工清单——#24。
6. **libmpv2 6.0.0 悬垂 bug**：`create_client(Some(name))` 的 CString 在 if-let 块尾提前释放 → 野指针 → mpv 返回 NULL → `NonNull::new_unchecked` UB abort（raw 同形状调用不复现）；绕行 `create_client(None)`（name 仅装饰）——#26。
7. **status 形状**：`{sessions:[…], playing}`，单会话查询返回数组首条——#25。
8. **P0 实现形态**：单 crate 直接导出 `ling_plugin_create`（未拆 rm 式壳 crate）；控制页 `include_str!` 静态 HTML（无 node/vite）+ core-ui 贡献（未装载静默忽略）+ `player.ui.page` 直出；stop 即摘会话（player.db 留 P6）——#27。
9. **ling Drop 恢复**：`impl Drop for Kernel → shutdown` 在排除陈旧 builtin 插件 ABI 根因后恢复（测试防插件端口泄漏），L 系列回归全绿。
10. **环境陷阱（备忘）**：`cargo build -p <pkg>` 不重建 builtin-plugins → 陈旧 `libcore_ui.so` 与现 ling-sdk ABI 不符导致 `ling serve` SIGSEGV；回归前先 `cargo build --workspace`。
