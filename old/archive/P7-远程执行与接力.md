## 范围（对照 `docs/01` §9 P7）

- **控制平面（§5.6，落 `control.rs`）**：player 自建 HTTP 平面（不改 rm、不占 ling 端口面）——bind `0.0.0.0`，端口候选 **7917**（忙退 7918/7919/7920，**全忙平面关闭降级**、插件照常装载）；非阻塞 accept + 50ms 轮询 + `AtomicBool` 停机 + 每连接独立线程（读写 5s 超时）；`ControlHandle{port, stop, join}`（`shutdown` join ≤~100ms，Drop 兜底）随 `PlayerState.control` 持有；`deactivate()`/`on_deactivate` 双入口 `teardown`（关平面 → flush → 拆会话 → 杀非 background，幂等）。端点：`GET /control/status`、`GET /remote/caps`、`POST /sync`、`POST /remote/run`、`GET/POST /remote/run/{id}`（status/stop/input/log）——**所有错误 → HTTP 400 + `{"error":{code,message}}`**（未知路径亦 400），`httpmini::reason` 补 400/500 文案。
- **发现对端**：读 rm `sync.status` peer 表（只读，`from_rm_err` 翻译）；`peer` 入参三解析——含 `:` → 直给 `host:port`（剥 http(s)://、尾 `/`、路径），不含 `:` → device_id 查 peer 表取 host 拼 **7917**，缺省 = 单配对推导（**0 对端 → P303**、**>1 未指定 → P100**；P201 保留 cast）。`derive_targets` 空 host 跳过，`sync_targets` 随 status 外发。
- **会话同步（§5.9）**：`persist_session(session, Option<f64>, SyncMode)` 统一写穿出口——pause/resume/set_volume/set_subtitle/stop、Paused/Finished 事件、停机 flush = **Immediate**；seek/Progress = **Throttled**（5s 或 1% duration 先到者，`sync_marks` 按 content_id 盖戳真变化才推）；Failed 不推、目标空不推、store 缺失/viewer/无 cid 跳过。`maybe_sync` 组 `session.sync` 报文（严格 §5.9 表，无 aid/rate）→ 后台线程 `push_sync`（2s 超时静默）。接收侧 `POST /sync` → `SyncPayload::parse`（type/cid/did 非空、position 有限≥0、volume 有限 0..=1、subtitle i32、updated_at>0，不过 P100）→ `Store::apply_sync` **LWW**：自报 device_id → `{applied:false, reason:"self"}` 不写、`p.updated_at < existing` → `reason:"stale"`、**同秒并列后到者胜**（严格小于才拒，防同秒先到吞掉后到暂停报文）；合入保留本机 `audio_track`/`playback_rate`，新行预置 0/1.0。`stamp`（now + 本机 device_id）替代原 `upsert_now`，盖戳与写库分离。
- **远程执行面（§5.6/§5.12）**：发起侧 6 方法 `player.remote.{caps,run,status,stop,input,log}` 经 `remote_request`（10s 超时；传输失败/响应畸形 → **P303**；对端错误原码透传 `CallError::new(code, msg)`）+ `player.control.status`（`{enabled, port, device_id, sync_applied, sync_ignored, sync_targets}`）。`remote.run` 走接收侧 `run::run` **全链 P5 沙箱**（`ensure_content_id` 先于对端解析——缺 content_id 本地 P100；video → 接收侧 P103 回传）；`remote.status/stop/log` 先 `get_value` 校验 run_id（未知 P100）；**画面回传 headless 降级为日志尾**——`remote.log {run_id, stream?}` 读 stdout/stderr 沙箱文件 tail 8KB（`{run_id, stream, data, bytes}`，stream 白名单，缺文件空串）。
- **输入传输（§5.15，落 `run.rs`）**：运行 stdin 改 `Stdio::piped()`，`RunRegistry` 元组 → 命名结构 `{rows, inputs: Mutex<HashMap<String, ChildStdin>>}`（spawn 后 `child.stdin.take()` 登记；`set_exited` 收束清 stdin）。`remote.input {run_id, event}`：**发起侧先 `validate_input`**（touch x/y 0..=1 + down|move|up、key 非空 + down|up、text ≤4096 字节、back 仅 press、未知 type → P100）再发包 → 接收侧 `write_input` 把事件序列化为 **JSONL 单行 + `\n`** 写沙箱进程（text 不裸写）。**门禁 = `remote.run` 命名空间**：`valid_run_id` 字符集 `[A-Za-z0-9_-]` 先验（防穿越），视频会话 `ps_*` 不在运行表 → 本机/跨机同径 **P100**（§5.15 安全面）。
- **错误面（§8）**：新增 **P303 远程执行不可用**（0 配对、connect 失败、响应畸形、全端口忙关闭后的发起侧调用）；入参类全归 **P100**（>1 对端、缺 content_id、坏事件、未知 run_id、坏报文）；**P201 口径澄清**仍仅 cast。
- **安全口径登记（#74）**：控制平面**无请求级鉴权**（bind 0.0.0.0 局域网信任，同 lite `/cast` 与风险 #7 同族）；`/sync` 只写会话库且自报拒写；`/remote/run` 仅对端本机目录 app/game + 全链沙箱；输入仅 `remote.run` 命名空间；日志尾只读自身沙箱文件。
- **延后口径（#75）**：逐帧画面回传不落——`Sink::write_video_frame`/`Router::select_sink → Box<dyn Sink>`（#51）与 `rtt_ms`（#52）**继续延后**（headless 降级日志尾，无逐帧消费者，#40 立场延续）；UI 远程执行页无方法面消费者，同 #62 留后续。

## 关键决策与登记（附录 B）

- **#69 控制面形态**：自建 HTTP 平面（7917 候选、忙退、全忙降级）+ `remote.*` 六方法；headless 画面回传降级 `remote.log` 日志尾（stdout/stderr 沙箱文件 tail 8KB）。
- **#70 对端发现**：三解析（直给 host:port / device_id 查 peer 拼 7917 / 缺省单配对）；0 → P303、>1 → P100；P201 留 cast。
- **#71 同步语义**：force/节流双清单（Immediate 8 类、Throttled 2 类）、LWW 严格小于（同秒后到者胜）、自报拒写（self）、`POST /sync` 200 `{applied, reason?}` 三态、`sync_applied/ignored` 计数与 `sync_targets` 可观测、推送线程 2s 静默。
- **#72 输入 transport**：stdin JSONL 单行（四类事件统一，text 不裸写）；门禁 = `remote.run` 命名空间（`ps_*` 视频会话本机/跨机均 P100）；发起侧先校验再发包。
- **#73 错误码**：**P303 = 远程执行不可用**（0 配对/连接失败/报文畸形/平面全忙）；入参类 P100；与 P201（cast 对端不可达）边界写明防混。
- **#74 安全口径**：控制平面无请求级鉴权（bind 0.0.0.0 局域网信任，同 lite `/cast`、风险 #7 同族）——`/sync` 只写库 + 自报拒写，`/remote/run` 仅本机目录 app/game + 全链 P5 沙箱，输入仅 run 命名空间。
- **#75 延后立场**：Sink 写帧面（#51）与 `rtt_ms`（#52）**继续延后**（headless 降级日志尾 → 无逐帧消费者，#40 立场延续）；UI 远程页同 #62 留后续。
- **#76 验收口径**：p7_acceptance 三用例（先 boot 接收侧占 7917、单向配对、字节相同 movie 同 content_id、直连 HTTP 断言、精确计数）。
- **实现花絮**：配对码须由**对端**生成（`pairing_code` 调 B 侧、`device.pair` 调 A 侧，m3 同径）——e2e 首轮 F401 即此因；e1 同秒并列竞态靠「后到者胜 + 全行载荷」天然无害（任何胜出行都含最终音量/字幕，位置差 ≤0.3s 容差内）。
