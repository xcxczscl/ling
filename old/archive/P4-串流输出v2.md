## 范围（对照 `docs/01` §9 P4）

- **自动/手动路由（§5.3.2，落 `router.rs`）**：三输入落地——① 接收器能力：lite 心跳负载与 `player.receiver.list` 行增 `codecs`（lite 宣称保守基线 `["h264","aac"]`，mpv 实际能解更多、宣称的是保证面）；② 内容编码：`player.cast` 时对 rm 流 `ffprobe -select_streams v:0` 取视频 codec_name（失败按「不宣称」走兜底）；③ 带宽：`BandwidthEstimate::fixed()` 100 Mbps（设计允许的可选 ping RTT 未做，#52）。`auto_select_mode`：对端支持内容编码 → **A**；不支持但宣称 h264 且 ≥20 Mbps → **B**；否则 → **C**；永不 D。`player.cast` 的 `mode` 缺省从 P3 的「A」改为**自动**（§5.3.2 `user_override=None` 语义），`"A"/"B"/"C"` = 用户强制，`"D"`（电视协议占位）/未知/非字符串 → **P100**。
- **模式 B/C 现场转码（§5.3.1「对端直接从 7914 拉分块流」，落 `proxy.rs`）**：路由表增 `kind: Bytes | Transcode{mode}`，URL 形态与 A 完全一致（`/s/<stream_id>/<token>`，接收器无感）；`GET` 忽略 Range → `200 + Transfer-Encoding: chunked`，ffmpeg 子进程 stdout 逐块下发——**B** = `libx264 -preset ultrafast` + `aac` → `mpegts`，**C** = `mjpeg` → `mpjpeg`（`-an` 无音频，保最低延迟）；客户端断开 → kill+wait 子进程（防孤儿转码）；cast 前置 `ffmpeg -encoders` 探测（按模式缓存），缺编码器 → **P104**；HEAD → 405。
- **lite 接收面（§5.13/§5.4）**：`validate_cast` 收 A/B/C（缺省 A；D/未知 → `accepted:false unsupported_mode`），`status.mode` 记实际投送模式，心跳外发 `LITE_CODECS` 宣称；A/B/C 皆由 `MpvBackend` 起播（mpv 运行时探测解复用：原始流/mpegts/mpjpeg 同一路径）。
- **电视协议 Sink 接口占位（§5.4，落 `tv.rs`）**：`TvProtocolSink` trait 照设计签名（`discover → Vec<TvDevice>`、`cast(url)`），`NullTvSink` 首版实现：`discover` 恒空列表、`cast → P201 占位`。§6.3 `Sink` trait 帧写入面与 §6.4 `Router::select_sink` **不落**（A=代理转发、B/C=ffmpeg 管道均无逐帧消费者——#40 反死代码立场，延 P7 画面回传，#51 登记）。
- **事件/UI 增量**：`player.cast.ended` 载荷增 `mode`（#55）；控制页接收器卡增模式下拉（自动/A/B/C，D 禁用），投屏时按所选模式下发。

## 关键决策与登记（附录 B）

- **#50 自动路由三输入**：心跳 `codecs` 宣称（lite 保守基线）+ cast 时 ffprobe 内容编码 + **`mode` 缺省改 auto**（P3 语义变化，p3 e2e 改显式 A）。
- **#51 占位与反死代码**：`TvProtocolSink`/`NullTvSink` 落类型面；§6.3 Sink 写帧面、§6.4 `select_sink` 不落（无逐帧消费者，#40 立场，延 P7）。
- **#52 带宽**：设计「P4 起可选 ping RTT」为可选项——沿用固定 100 Mbps，不主动 ping（防惊群、免 e2e 耗时）。
- **#53 转码机制**：ffmpeg 子进程 + `kind` 路由（URL 与 A 同形）、chunked 现场流、B=H.264+AAC→mpegts / C=mjpeg→mpjpeg、断开杀进程、缺编码器 P104 前置、HEAD 405。
- **#54 lite 收发面**：A/B/C 接受（D/未知 → `unsupported_mode`）、`status.mode` 记实际模式、`LITE_CODECS` 宣称随心跳。
- **#55 事件增量**：`cast.ended` 增 `mode`（增量字段，P3 消费方不破坏）。
- **#56 e2e 口径**：自动 A（h264）、自动 B（mpeg4 夹具转码对端起播 = §9 核心）、手动 C/A 覆盖与 D/未知面；p3 用例适配显式 mode 与合法化后的错误码迁移。
