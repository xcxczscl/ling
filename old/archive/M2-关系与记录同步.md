## 范围（对照 `docs/01` §12.1 / §12.2）

- **关系（Connection）**：类型白名单、CRUD、唯一约束、墓碑（30 天宽限）
- **记录同步**：op 只增流水（seq 自增 + op_id 幂等）、peer 进度（known_seq）、导出/应用合并
- **合并规则**（§7.5 / A-16）：同 op_id 幂等跳过；字段级 edit-edit → `sync_conflict` 队列 + 较晚 ts 自动胜；delete-edit 墓碑默认胜；resolve = 更晚新 op（不复活）
- **设备管理**：pair/forget/list（M2 简化：码 + 指纹登记，无 Ed25519）
- **传输**：文件桥（export/import JSON op 包）；`sync.run` 返回 bridge 提示
- **UI**：devices 静态页 + 事件 `SYNC_DONE` / `SYNC_CONFLICT`

## 关键决策 / 偏差登记（docs/01 附录 B #11）

1. **无真网络** → 文件桥（`sync export` / `sync import`）；领域层与传输解耦，M3 换 LAN。
2. **配对简化**：无 Ed25519；`device.pair <code>` 登记 `peer`（id/addr/fingerprint 占位）。
3. **resolve = 新 op**（A-16）：`conflict_resolve` + 胜方完整对象 `entry_update`，对端旧值打不过。
4. **字段级冲突写回**：`sync_conflict.my/their_value` 存字段级 JSON 标量；resolve 时按 `field` 合回对象并保留未冲突字段。
5. **本地 op 一律经** `rm_semantic::op_append` / `rm_sync::oplog::append_local`（kind 白名单见 merge.rs）。
6. **placement/state 合并最小集**：物理层本地权威；`state_change` 仅归属设备可改写。

## 复验命令

```bash
cd /root/workspace/resources-manager
cargo test --workspace
cargo test -p rm-plugin --test m2_acceptance
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
# 文件桥 E2E（示例）
cargo build -p rmgr
BIN=target/debug/rmgr; TMP=$(mktemp -d)
$BIN --db $TMP/a.db location add $TMP/root_a --label A
$BIN --db $TMP/b.db location add $TMP/root_b --label B
$BIN --db $TMP/a.db entry create --title 'A片' --kind work
$BIN --db $TMP/a.db device pair CODE1234 --peer dv_peer_b --fingerprint fp:b
$BIN --db $TMP/b.db device pair CODE1234 --peer dv_peer_a --fingerprint fp:a
$BIN --db $TMP/a.db sync export $TMP/ops.json
$BIN --db $TMP/b.db sync import $TMP/ops.json
$BIN --db $TMP/b.db entry list
# 校验和
cd /root/workspace && sha256sum -c archive/M2-files.sha256 -s
```
