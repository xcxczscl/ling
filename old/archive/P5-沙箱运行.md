## 范围（对照 `docs/01` §9 P5）

- **沙箱隔离链（§5.8，落 `sandbox.rs`）**：`prepare`（父进程构建，可报 P301/P302）→ `install`（`Command::pre_exec`，fork 后 exec 前）顺序 **setsid → `prctl(NO_NEW_PRIVS)` → `landlock_restrict_self` → `prctl(PR_SET_SECCOMP=22, SECCOMP_MODE_FILTER)` → `setrlimit`（CORE=0 不留内存快照、NOFILE 限句柄）**，任一步失败 → spawn 冒泡 **P301**。fs 面 = Landlock（沙箱目录 RW + `sandbox_opts.allow_dirs` 逐项规范化，`DENIED_ALLOW_ROOTS` 系统根 13 项拒绝 → **P302**；非目录对象仅 `EXECUTE|WRITE_FILE|READ_FILE` 合法，逐位探针实证掩码 `0x7` 否则 `add_rule` EINVAL）；net 面 = seccomp BPF 按架构拦网络与 io_uring（x86_64 `41/42/43/53/288/425–427`、aarch64 `198/203/199/202/242/425–427`，动作 `ERRNO|EPERM` 优雅失败），`allow_network=true` → 不装（`granted`），非目标架构/audit 失败 → `degraded`——`isolation={fs, network, no_new_privs, session}` **如实上报不虚报**。
- **方法面（§5.12，落 `run.rs` + `lib.rs` 接线）**：`player.run`（placement/content 兼容入参、**仅 app/game** 其余 → **P103**、`sandbox_opts` 类型错 → **P100**、allow_dirs 非法 → **P302**、rm `F501/F503` → **P101/P102**、文件不存在 → P101、隔离/启动失败 → **P301**；响应 `{run_id, pid, path, sandbox_dir, isolation}` 原表 `{run_id}` 增补）+ `player.run.list`（插入序 `{rows[]}`，行含 state/exit_code/isolation 等 12 字段）+ `player.run.stop`（杀组，未知 run_id → **P100**、已退出 → `stopped:false` 不报错，含 allow_background 运行）；`player.run.exited` 事件（信号杀 → `128+N`，wait 失败 → `-1`）。
- **进程与环境**：`env_clear` 后仅 PATH/HOME(沙箱)/TMPDIR(沙箱内)/LANG=C，CWD=沙箱，stdin null，stdout/stderr 父进程开好句柄落沙箱 `stdout.log`/`stderr.log`（继承句柄绕开路径再校验）；无执行位 best-effort `chmod +x`（shell 脚本类夹具）；run_id = getrandom 12B hex（`getrandom` crate，遵守「不新增 crates、手写 extern」约束）。
- **生命周期**：监控线程 100ms `try_wait` reap + 状态翻转（`running→exited` + exit_code）+ 广播 `player.run.exited`；停用/停机双入口（`deactivate()` 与 `on_deactivate` 回调，kernel `stop_plugin` 链）**幂等**调 `kill_non_background`（杀 `state=running && !allow_background` 全部进程组）——「player 退出即杀」默认面与 `allow_background` 授权豁免并存，`player.run.stop` 为唯一手动停通道。
- **验收口径（#62）**：headless 下验「进程起、三隔离面生效、退出码/事件收束、停机即杀」；「画面本机显示」不验（同 #24 惯例）；控制页无运行入口（`player.run` 未被任何页面引用，UI 留后续需要时补）。

## 关键决策与登记（附录 B）

- **#57 方法面**：`player.run` 响应增补 `{run_id, pid, path, sandbox_dir, isolation}`；新增 `run.list`（插入序）/`run.stop`（未知 P100、已退出 false）；仅 app/game → 其余 P103；`isolation` 四字段如实上报。
- **#58 实装选型**：设计表 seccomp+namespace+cgroups 在容器/普通权限环境不可落地 → 落 **Landlock（fs）+ seccomp（net）+ nnp + setsid + rlimit**；降级（degraded/granted）如实标注，不虚报。
- **#59 `PR_SET_SECCOMP` 常量教训**：曾误写 **28**（=PR_GET_TIMING）——prctl 返回 0 但过滤器从不安装、socket 照常成功；raw seccomp(317) 路径先证可用（排除 BPF 字节/struct 布局问题），objdump 对比 C 调用点 `edi=0x16` 破案（真值 **22**）；t6 断言面覆盖不到网络 → 补 **t7 实弹**（`current_exe --ignored` helper 直接 socket）。
- **#60 架构表修正**：aarch64 `accept4` 曾误 204（=getsockname）→ **242**（asm-generic）；x86_64 表逐号对照 `unistd_64.h` 全对。
- **#61 e2e 判活**：容器 PID1（opencode）不回收孤儿 → `kill(-pgid,0)` 对「仅剩僵尸」的组恒真；`wait_gone` 改 **`/proc/<leader>` 轮询**（leader 由监控线程 try_wait 收割）；正向断言仍用组探针。
- **#62 验收口径与 UI 范围**：headless 验三隔离面/生命周期，窗口画面留有窗口环境；控制页无运行入口，方法/事件面完备即可，UI 留后续。
