## 范围（对照 `docs/01` §9 P3）

- **模式 A 本地代理（§5.3.1）**：`httpmini.rs`（手写 HTTP/1.1 请求解析/响应，无 web 框架依赖）+ `proxy.rs`（进程级单例：端口 7914 → 7916..7930 顺延（跳过 7915 lite），全忙 **P203**；128-bit 随机代理 token（getrandom）、路由表 `{stream_id → rm_url+token}` 内存态、坏 token/未知流统一 403、单请求单连接 `Connection: close`、Range/`Accept-Encoding: identity` 透传、上游 200/206/403 状态与 Content-Length/Content-Range 原样回传、body 流式拷贝）。对端拿到的字节与直读 rm 流逐字节一致（e2e 整流 + Range 分段对拍）。
- **局域网发现（§4.5/§5.13）**：`discovery.rs`——lite 每 1s UDP 心跳（`127.0.0.1` + 广播 `255.255.255.255` 到 7916；主动宣告、被动监听，**不扫描局域网**、**不依赖 rm peer**）；负载 `{id,name,port,state}`、源 IP 为地址、TTL 3s；监听首选 7916、被占退 OS 临时端口并经 `receiver.list.discovery_port` 外发（ling `lib_seq` 每次装载复制 .so 独立 dlopen → 静态表不跨实例——e2e 三用例三次装载实证后固化，lite `--hb` 显式指向本实例端口）。
- **投屏编排（§5.12 `player.cast`）**：`cast.rs`——会话须存在（**P401**）且 mpv 会话（viewer → **P103**）、mode 仅 `"A"`（B/C/D → **P100 待 P4**）、未知/不可达接收器 → **P201**、接收器 `accepted:false` → **P202**；独立 `stream.open`（不复用本机会话句柄）→ ensure_proxy + 路由注册 → `sender_host_for`（UDP connect 查路由取本机 IP）→ POST `http://<rx>:<port>/cast`；并行镜像（本机会话不动、对端从流起点起播）；重投先停旧投（`cast.ended reason=replaced`）；会话 `stop` 自动结束（摘路由 + `POST /stop` 通知对端 + `reason=stopped`）；对端播完自回待机，发送端不轮询。
- **lite 接收器（§5.4 两套构建同库）**：`lite.rs` + `src/bin/player_lite.rs`（`[[bin]] player-lite`）——`POST /cast`（§5.13 照表 + mode B/C → `unsupported_mode`、mpv 初始化失败 → `decoder_error`、`autoplay` 尊重）、`GET /status`、`POST /stop`（后两者实装增补）；`MpvBackend` 起播（headless 继承 `PLAYER_VO`/DISPLAY 判定）、EOF/失败 → 回待机、`state` 心跳与 /status 同源派生（idle/playing/paused）；参数 `--port`（0=OS 分配，stdout `PORT=` 回显）、`--name`、`--id`（默认随机）、`--hb`（心跳目的地覆盖）。
- **方法/事件**：新方法 `player.cast`、`player.cast.stop`、`player.receiver.list`（均附录 B #42 登记）；事件 `player.cast.started/ended` 照 §5.12；cast 响应 `{receiver_id, mode, accepted}`（原表 `{}` 增补）。
- **UI（#48）**：控制页「局域网接收器」卡——`receiver.list` 3s 轮询（name/addr:port/state，播放中高亮）、点击投屏（需会话）、`停止投屏` 按钮。

## 关键决策与登记（附录 B）

- **#42 方法面增补**：`receiver.list`/`cast.stop` 新方法 + cast 响应 `{receiver_id, mode, accepted}`（原表 `{}`）。
- **#43 心跳口径**：§5.13「复用 rm peer」与风险 #6「不依赖 rm」并存 → 取不依赖 rm（loopback + 广播双目的地），rm peer 单播留 P4+。
- **#44 多实例端口事实**（e2e 实证）：`lib_seq` 每次装载复制 .so 独立 dlopen → 静态表/监听不跨实例共享；代理顺延池 7916..7930、发现 7916 忙退临时端口并经 `discovery_port` 外发、lite `--hb` 接线；坏 token 403、单请求单连接。
- **#45 cast 语义细化**：mpv-only/mode A/独立开流/并行镜像（进度联动属 P7）/media_info 尽力（codec 协商属 P4）/重投 replaced/stop 自动停投/不轮询 EOF/错误映射 P103·P100·P201·P202·P401。
- **#46 lite 控制面增补**：`GET /status`、`POST /stop`；拒绝 reason 面（`unsupported_mode`/`decoder_error`/`bad_request`）；state 同源派生。
- **#47 lite 构建形态**：同 crate `[[bin]]`，`--port 0` + `PORT=` 回显（e2e 免端口竞态）。
- **#48 投屏 UI**：控制页接收器卡与投屏/停投按钮。
- **#49 e2e 口径**：同机双进程 loopback 链路 = 「对端正常播放」（/status playing + position 前进）；7914 断言以本环境端口事实为准；多用例端口互扰由 #44 消解。
