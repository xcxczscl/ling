## 三、关键决策（编码期裁定，均已登记 01 附录 B 第 14 条）

1. **订阅回调带主题**：`Callback = Arc<dyn Fn(&str, Value) + Send + Sync>`——侧车转发事件需要主题；插件 SDK 回调只见载荷，经 `wrap_plugin_callback` 适配层保持 SDK 接口不变。
2. **方法注册异步窗口**：侧车 `register_method` 在 activate 之后到达，装载返回即视为激活——短暂 `E_METHOD_MISSING` 属正常窗口；测试/界面按重试处理；"注册完成"握手留后续。
3. **崩溃善后时序**：断连→注销效应（方法/订阅）→广播 `crashed`→`restart=on-crash` 时 200ms 后经 `loader::load` 重装；优雅停用路径置 `stopping` 不触发崩溃善后；deactivated 等待 5s、退出等待 5s 后强杀。
4. **基准门槛**：07 §3 "<1µs" 为 release 目标；L6-4 在 debug 下以 <10µs 门槛验证"不受侧车影响"的不变性（20000 次 `demo-b.add` 调用平均耗时）；release 复测留发布硬化。
5. **Python 依赖**：环境初始无 python3，已 `apk add python3`；发行包需在运行环境声明 Python3 依赖（仅示例侧车需要）。
6. **调用超时**：侧车同步 invoke 30s（04 §3 同步 call 语义），复用 `E_TIMEOUT`；侧车自身 `call` 回宿主在独立线程处理，避免自死锁。
