# other/stu

个人学习目录。**不属于项目设计文档**，与 `docs/` 的规矩完全脱钩。

## 三条约定

| 约定 | 说明 |
|---|---|
| 不编号、不做简版 | `docs/` 的编号与「详细版 + 简版」规则只服务于可评审的设计文档，这里不适用 |
| 不进评审、不登记 | 不出现在 `docs/ling/00-总览与术语.md` 的文档地图里，也不进 `docs/log/` |
| 可以随便改 | 这里的文件随时重写，不需要变更记录 |

## 文件

| 文件 | 作用 |
|---|---|
| `README.md` | 本文件，目录说明与约定 |
| `学习路线.md` | 起点、六个阶段、每阶段的自检题、概念分级、疑问清单 |
| `新会话开场提示.md` | 在另一个会话里开始学习时，直接复制过去的开场提示 |
| `笔记/` | 学习笔记，一天一个文件或一个主题一个文件 |

## 边界

这里只放「我自己要学的东西」。项目该留的内容（设计、代码、决策、日志）一律在 `docs/`、`main/`、`plugins/` 与 `other/` 的其他子目录里，不要混进来。

反过来也成立：学习笔记、概念解释、练习题的答案，不要往 `docs/` 里塞——那会让设计文档变难读，上一版已经吃过这个亏。
