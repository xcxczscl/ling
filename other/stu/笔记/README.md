# 笔记

一个主题一个文件，命名 `YYYY-MM-DD-主题.md`，如 `2026-10-29-动态库与ABI.md`。

## 写什么

只写**自己讲得出来的话**，不抄文档原文。抄一遍不算学会，能用大白话复述一遍才算。

建议每份笔记三块：

| 块 | 内容 |
|---|---|
| 它解决什么问题 | 没有它会怎样 |
| 我怎么理解它 | 用类比或自己的话，允许不严谨 |
| 还没弄清的地方 | 写清卡在哪，攒进 `../学习路线.md` 的 §7 |

## 不要写什么

不要写设计决策、不要写项目状态、不要复制 `docs/` 的表格。那些属于项目文档，改在 `docs/` 里改。
