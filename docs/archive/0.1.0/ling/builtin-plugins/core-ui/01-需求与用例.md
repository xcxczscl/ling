# core-ui 01 需求与用例

> 状态：已定稿 | 最后更新：2026-10-31
> 上级：`docs/ling/builtin-plugins/core-ui/00-总览与边界.md`

本文回答：界面上要能做哪些事、每件事成什么样、怎么判断做对了。

---

## 1. 需求从哪来

| 条目 | 本插件承担的部分 |
|---|---|
| `LING-REQ-075` | 卸掉 core-ui 后命令行仍可用——反过来说，界面不能是任何能力的唯一入口 |
| `LING-REQ-116` | 界面崩溃不影响宿主，2 秒内自动重启并可重连 |
| `LING-REQ-072` | 界面与命令行走同一条调用路由，不另开一套 |
| `LING-REQ-078` | 内置插件无特权，它调的每个方法都是普通方法 |
| `LING-REQ-115` | 只绑回环，不对外暴露 |

## 2. 场景

### 2.1 打开界面

装好 ling 之后，使用者想看看现在是什么状态。

要成什么样：

- `webui` 版：宿主启动后自动打开浏览器到 `127.0.0.1:8010`（端口被占时顺延，实际端口从 `registry.json` 的 `ui_port` 读）。
- `desktop` 版：双击图标直接出窗口，不需要浏览器。
- 打开后 1 秒内显示插件列表，不是白屏转圈。

### 2.2 看装了哪些插件

要成什么样：

- 每个插件一张卡片或一行：插件名、版本、状态、类型。
- 状态用颜色区分：已启用（绿）、已停用（灰）、启动失败（红，附原因）。
- 顶部一行汇总：共几个、几个在用。

### 2.3 装一个插件

要成什么样：

- 点「安装」，选一个目录。
- 装成功：列表里多一条，状态「已启用」，并提示「装好了」。
- 装失败：弹出原因（用命令行那套人话文案），不留半截文件。
- 装的过程中按钮变灰，防重复点击。

### 2.4 停掉一个插件

要成什么样：

- 点「停用」，状态变「已停用」。
- 如果别的插件依赖它，先提示「这会连带停用 demo-b，确定吗」，确认后才执行。
- 停用后数据还在，卡片上注明。

### 2.5 卸载

要成什么样：

- 点「卸载」，先问「保留数据还是连数据一起删」。
- 两个选项都写清后果（保留：`data/` 留着，下次装回来能用；删除：不可恢复）。
- 卸载完成后列表里消失。

### 2.6 翻日志

要成什么样：

- 选一个插件，看它最近的日志。
- 能按级别筛（错误 / 警告 / 信息）。
- 能自动刷新（每 2 秒）。
- 日志量大时不卡：只渲染最后 200 行，往上翻再加载。

### 2.7 改配置

要成什么样：

- 列出某个插件的全部配置键。
- 值按类型给对应控件：布尔给开关、数字给输入框、对象给文本框（JSON）。
- 改完立即生效，不需要重启。
- 保存失败时说明原因，输入框保留用户填的内容，不要清空。

### 2.8 看定时任务

要成什么样：

- 列出任务：名字、cron、目标方法、上次触发时间。
- 能新增、停用、删除。
- cron 写错时，在输入框下面直接提示哪一段错了。

### 2.9 界面崩了

要成什么样：

- 宿主不受影响，其他插件照常工作。
- 2 秒内自动重启一次（`LING-REQ-116`）。
- 浏览器侧刷新即可恢复，不用重开宿主。
- 连续崩三次就停下，在命令行 `ling plugins` 里显示「启动失败」并附原因。

## 3. 用例与验收标准

编号 `CU-` 开头。

| 编号 | 场景 | 期望 | 怎么判 |
|---|---|---|---|
| CU-01 | 宿主启动后打开界面 | 1 秒内出现插件列表 | 计时 |
| CU-02 | 列表状态与命令行一致 | 两边条目与状态相同 | 逐条比对 |
| CU-03 | 界面装一个插件 | 列表新增且状态正确 | 命令行 `plugins` 复核 |
| CU-04 | 装一个坏插件 | 显示人话原因，不留残件 | 目录检查 |
| CU-05 | 停用有下游的插件 | 先提示会连带谁 | 对话框文案 |
| CU-06 | 卸载时选「删除数据」 | 目录整个消失 | 文件系统 |
| CU-07 | 日志筛选 | 只剩选中级别 | 每条都含对应标签 |
| CU-08 | 日志 10 万行 | 界面滚动不卡 | 主观观察 + 首屏时间 |
| CU-09 | 改一个布尔配置 | 立即生效 | 命令行读回 |
| CU-10 | 配置保存失败 | 输入框内容保留 | 断开宿主后试 |
| CU-11 | 任务 cron 写错 | 输入框下方提示 | 错误文案含段名 |
| CU-12 | 强杀界面进程 | 2 秒内重启，宿主不受影响 | 观察进程与 `plugins` |
| CU-13 | 连崩三次 | 停止重启，状态为失败 | `ling plugins` |
| CU-14 | 用别的用户的浏览器访问 | 连不上（只绑回环） | `netstat` 核对监听地址 |
| CU-15 | 卸掉 core-ui | 命令行全部子命令可用 | 逐条跑一遍 |
| CU-16 | 关窗口时选「退出 ling」 | 宿主随之退出，定时任务停止 | 进程检查 |

## 4. 本期明确不做的

| 不做 | 什么时候做 | 为什么现在不做 |
|---|---|---|
| 远程访问与多用户 | 不做 | 单机个人工具，加了就要做账号与加密 |
| 主题与布局自定义 | 不确定 | 先用一套固定布局，用出问题再改 |
| 插件详情页（README、权限说明） | 不确定 | 需要清单里带更多字段 |
| 图表（调用量、耗时趋势） | 不确定 | 要先有指标采集，那是另一件事 |
| 国际化 | 不做 | 只有中文 |
