# core-plugin-manager 01 需求与用例

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-plugin-manager/01-需求与用例.md`

## 1. 需求从哪来

挂在 `078`（无特权）、`081`（可卸载）、`039` 至 `051`（依赖图与调和）、`010`（「只剩 data/ 算未安装」）之下。

## 2. 场景

### 2.1 看某个插件牵连了谁

给上游（它依赖谁）与下游（谁依赖它，含传递）；缺依赖的标出来。

### 2.2 找出白占空间的数据

列出只剩 `data/` 的目录与各自大小、合计大小。**只列不删。**

### 2.3 一次停掉一组插件

按拓扑序执行：停用先停下游。中途失败就停在失败处，报告已停哪些、哪个失败；不回滚已执行的。

### 2.4 动手前先算一遍

给操作与插件名，返回会激活、会停用的名单，**不改变任何状态**。

## 3. 用例与验收标准

`CM-01` 至 `CM-10`：孤儿扫描、无孤儿、占用统计、依赖树、缺失项、预演、批量停用顺序、中途失败、卸掉本插件、大目录统计。后五项依赖 M3，验收时标「本期不适用」。

## 4. 本期明确不做的

删除孤儿数据（不做）、依赖树与预演与批量（M3）、插件市场（非目标）、版本对比与降级（M3 之后）。
