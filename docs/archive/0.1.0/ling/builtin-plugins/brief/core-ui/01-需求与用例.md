# core-ui 01 需求与用例

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-ui/01-需求与用例.md`

## 1. 需求从哪来

挂在 `075`（卸掉界面命令行仍可用）、`116`（界面崩溃不影响宿主）、`072`（同一条调用路由）、`078`（无特权）、`115`（只绑回环）之下。

## 2. 场景

### 2.1 打开界面

`webui` 版自动开浏览器，`desktop` 版直接出窗口；1 秒内出现插件列表，不白屏转圈。

### 2.2 看装了哪些插件

每个插件一行：名字、版本、状态（颜色 + 文字）、类型；顶部汇总总数与在用数。

### 2.3 装一个插件

选目录，装完列表多一条并提示成功；失败弹人话原因、不留残件；处理中按钮变灰。

### 2.4 停掉一个插件

状态变「已停用」；有下游时先提示会连带谁；数据保留。

### 2.5 卸载

先问「保留数据还是连数据一起删」，两个选项都写清后果，删除项标明不可恢复。

### 2.6 翻日志

按插件筛选、按级别筛、可自动刷新；只渲染最后 200 行，往上翻再加载。

### 2.7 改配置

按值类型给控件；改完立即生效；保存失败时保留输入内容并说明原因。

### 2.8 看定时任务

列出任务与上次触发时间；能增删停用；cron 写错时当场指出哪一段错了。

### 2.9 界面崩了

宿主不受影响；2 秒内重启一次；连续三次后停止并在 `ling plugins` 里显示失败原因。

## 3. 用例与验收标准

`CU-01` 至 `CU-16`：打开、列表一致、安装、坏插件、连带停用提示、删数据、日志筛选、十万行不卡、改配置、保存失败保留输入、cron 提示、强杀重启、连崩三次、只绑回环、卸掉后命令行可用、关窗口时退出 ling。

## 4. 本期明确不做的

远程访问与多用户、主题自定义、插件详情页、图表、国际化。
