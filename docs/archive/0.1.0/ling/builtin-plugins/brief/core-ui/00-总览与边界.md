# core-ui 00 总览与边界

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-ui/00-总览与边界.md`

## 1. 一句话

用鼠标把 ling 管起来：看装了哪些插件、装新的、停掉不用的、翻日志、改配置。

## 2. 它解决什么问题

命令行能做全部事，但要记命令、参数、插件名。界面把这些变成点击。命令行不删——两者共用同一套内核方法。

## 3. 两种形态

`webui` 版开浏览器标签页，三平台可用；`desktop` 版开独立窗口，目前只 Windows。两版**界面代码完全相同**，差别只在谁来显示页面。

## 4. 它不做什么

不做远程访问（只绑 `127.0.0.1`）、不做多用户、不做业务功能、不做插件市场、不做移动端适配。

## 5. 它在插件体系里的位置

侧车插件，独立进程。理由：它要跑 HTTP 服务、崩了不该拖垮宿主、将来换界面技术只换一个 exe。它只以客户端身份连管理端口，不读 `session.json`。

## 6. 没装它的时候

命令行全部可用；列表里少一个条目；已保存的界面偏好还在配置里。这是 `LING-REQ-075` 的意义——界面是便利，不是依赖。

## 7. 谁在用

使用者的日常主入口；界面的调用是单向的，其他插件不调它。
