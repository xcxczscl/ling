## 6. 十条常见误解

这些是读文档时最容易想反的地方。每条给「容易以为的」与「实际」。

| 容易以为 | 实际 | 出处 |
|---|---|---|
| 仓库里的 `data/` 是已经建好的目录 | `data/` 是运行期目录，首次启动才出现；仓库里没有 `main/data/`，`plugins/` 下也没有已建的数据目录 | `docs/ling/main/01-需求规格.md` §1.5 |
| 命令行能调任意插件的方法 | 只能调 `kernel.*` 方法；业务方法由插件之间调用，所以没有 `call` 子命令 | `docs/ling/main/04-详细设计/04-管理端口与命令行.md` §3.1 |
| 能力门禁是沙箱 | 只是审计与误用拦截：不管路径、不管频率，也拦不住绕过 `Context` 直接调系统 API | `docs/ling/main/06-安全设计.md` §4 |
| 卸载会把插件数据一起删掉 | 默认只删安装文件，`data/` 保留；加 `--purge` 才连数据删 | `docs/ling/main/01-需求规格.md` §3.1 |
| 热更新会卸载旧动态库 | 不卸载：复制到新文件名再加载，旧映射留在内存，因此重载次数多了会涨内存 | `docs/ling/main/04-详细设计/03-热更新.md` §2 |
| 侧车就是指 Python 插件 | 侧车指独立进程，C++ 也能写；`core-ui` 就是 C++ 侧车 | `docs/ling/main/03-架构设计.md` A-8 |
| 界面是宿主的一部分，界面崩了宿主也崩 | `core-ui` 是侧车，崩了只死自己，2 秒内重启 | `docs/ling/main/01-需求规格.md` 116 |
| 「单线程内核」意味着所有调用都排队 | 只有写串行；读走不可变快照，任意线程无锁读 | `docs/ling/main/03-架构设计.md` §5.3 |
| 插件版本由宿主按语义化版本管 | 宿主只校验三段式格式，不限制怎么递增 | `docs/common/02-版本号与兼容约定.md` §3 |
| MVP 不能升级宿主 | 能，手工替换二进制并重启；不含的只有侧车协议版本字段 | `docs/ling/main/11-MVP 范围.md` §4.1 |
