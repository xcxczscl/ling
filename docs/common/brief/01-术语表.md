# 01 术语表

> 状态：已定稿
> 最后更新：2026-11-03
> 依据：`docs/common/00-文档编写规范.md` §6.4

本文是 `docs/common/01-术语表.md` 的简版。术语只有结论，不解释来源与取舍；用法说明见详细版。

## 使用方式

- 全项目同一个概念只用一个词；换词之前先改这张表。
- 新术语先在表里登记，再在正文里使用。
- 每个术语给一句能独立看懂的解释，不用其他术语解释自己。
- 表格按拼音排序，不按出现顺序。

## 项目代号

代号用于需求编号，格式 `代号-REQ-三位数`。

| 代号 | 全称 | 一句话解释 | 首次出现 |
|---|---|---|---|
| `CUI` | core-ui 界面插件 | 提供 ling 的唯一人机界面，同时是所有插件网页的显示容器 | `docs/ling/builtin-plugins/core-ui/00-总览与术语.md` |
| `LING` | ling 宿主 | 负责加载和调度插件的主程序，自身不含业务内容 | `docs/ling/main/00-总览与术语.md` |
| `PLR` | 内容执行器插件 | 负责播放、查看、沙箱运行这类「把内容用起来」的动作 | `docs/plugins/player/00-总览与术语.md`（待编写） |
| `RM` | 资源管理插件 | 负责文件的归纳、整理、分类、同步、去重、备份 | `docs/plugins/resources-manager/00-总览与术语.md`（待编写） |

## 公共术语

ling 专属的机制术语（清单、效应账本、调和、激活计划）在 `docs/ling/main/00-总览与术语.md` §5 定义，不在这里重复。

| 术语 | 一句话解释 | 首次出现 |
|---|---|---|
| 插件 | 装在宿主里、提供某项具体功能的独立产物，可单独安装、卸载、更新 | `docs/ling/main/00-总览与术语.md` §1 |
| 插件名 | 命令行与界面上对某个插件的称呼，即 `ling plugins` 第一列显示的英文名（如 `demo-a`）；与「插件编号」、清单里的 `id` 是同一个东西 | `docs/ling/main/04-详细设计/04-管理端口与命令行.md` §4.1 |
| 侧车 | 以独立进程运行、通过本地套接字与宿主通信的插件形态 | `docs/ling/main/02-技术选型.md` §3.1 |
| 错误码 | 失败时返回的固定短标识，大写字母加下划线，如 `E_TIMEOUT` | `docs/ling/main/01-需求规格.md` §4.4 |
| 方法 | 插件注册到宿主、可被别的插件按名字调用的函数 | `docs/ling/main/01-需求规格.md` §3.2 |
| 轨道 | 插件运行方式的归类：装进宿主进程的算进程内一轨，独立进程的算侧车一轨 | `docs/ling/main/01-需求规格.md` §3.7 |
| 进程内插件 | 编译成动态库、装进宿主进程地址空间里运行的插件 | `docs/ling/main/02-技术选型.md` §3.1 |
| 面板 | 插件交给界面显示的那一份网页，装在隔离画框里，一个插件最多一个 | `docs/ling/builtin-plugins/core-ui/00-总览与术语.md` §6 |
| 内置插件 | 随宿主一起分发、默认已装好的插件，可以卸载，卸载后能用命令行装回 | `docs/ling/main/01-需求规格.md` §3.9 |
| 能力 | 宿主授予插件的权限名，如读写文件、执行命令 | `docs/ling/main/01-需求规格.md` §3.3 |
| 热更新 | 不重启宿主就换掉某个插件版本的整套流程 | `docs/ling/main/01-需求规格.md` §3.6 |
| 上下文 | 宿主交给插件的唯一入口对象，插件经它做一切需要宿主配合的事 | `docs/ling/main/01-需求规格.md` §3.4 |
| 设计令牌 | 界面用的颜色与尺度变量，名字以 `--ling-` 开头，换主题即换它的一套取值 | `docs/ling/builtin-plugins/core-ui/04-详细设计/04-设计令牌与主题.md` §1 |
| 事件 | 宿主广播给订阅者的通知，按主题名匹配送达 | `docs/ling/main/01-需求规格.md` §3.2 |
| 宿主 | 负责装载、调度、隔离插件的主程序，本身不含业务功能 | `docs/ling/main/00-总览与术语.md` §1 |
| 外壳 | 界面的固定部分：侧边栏、功能区、面板外框与设置界面，由 core-ui 自己绘制 | `docs/ling/builtin-plugins/core-ui/00-总览与术语.md` §6 |
| 载荷 | 一次方法调用或一条事件里携带的数据本体，单位是字节 | `docs/ling/main/01-需求规格.md` §4.1 |
| 主题 | 一套设计令牌的取值，内置亮色与暗色两套，切换后外壳与全部面板一起变 | `docs/ling/builtin-plugins/core-ui/04-详细设计/04-设计令牌与主题.md` §3 |
