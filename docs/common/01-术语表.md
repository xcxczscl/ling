## 使用方式

- 全项目同一个概念只用一个词；换词之前先改这张表。
- 新术语先在表里登记，再在正文里使用。
- 每个术语给一句能独立看懂的解释，不引用其他术语来解释自己。
- 表格按拼音排序，不按出现顺序。

## 公共术语

这些词在宿主、插件、构造文档里都会用到，集中在此定义。ling 专属的机制术语（清单、效应账本、调和、激活计划）在 `docs/ling/00-总览与术语.md` 第 5 节定义，不在这里重复。

| 术语 | 一句话解释 | 首次出现 |
|---|---|---|
| 插件 | 装在宿主里、提供某项具体功能的独立产物，可以单独安装、卸载、更新 | `docs/ling/00-总览与术语.md` §1 |
| 侧车 | 以独立进程运行、通过本地套接字与宿主通信的插件形态 | `docs/ling/02-技术选型.md` §3.1 |
| 错误码 | 失败时返回的固定短标识，用大写字母加下划线写成，如 `E_TIMEOUT` | `docs/ling/01-需求规格.md` §4.4 |
| 方法 | 插件注册到宿主、可被别的插件按名字调用的函数 | `docs/ling/01-需求规格.md` §3.2 |
| 轨道 | 插件运行方式的归类：装进宿主进程的算进程内一轨，独立进程的算侧车一轨 | `docs/ling/01-需求规格.md` §3.7 |
| 进程内插件 | 编译成动态库、被装进宿主进程地址空间里运行的插件 | `docs/ling/02-技术选型.md` §3.1 |
| 内置插件 | 随宿主一起分发、默认已装好的插件，可以卸载，卸载后能用命令行装回 | `docs/ling/01-需求规格.md` §3.9 |
| 能力 | 宿主授予插件的权限名，例如读写文件、执行命令 | `docs/ling/01-需求规格.md` §3.3 |
| 热更新 | 不重启宿主就换掉某个插件版本的整套流程 | `docs/ling/01-需求规格.md` §3.6 |
| 上下文 | 宿主交给插件的唯一入口对象，插件经它做一切需要宿主配合的事 | `docs/ling/01-需求规格.md` §3.4 |
| 事件 | 宿主广播给订阅者的通知，按主题名匹配送达 | `docs/ling/01-需求规格.md` §3.2 |
| 宿主 | 负责装载、调度、隔离插件的那个主程序，本身不含业务功能 | `docs/ling/00-总览与术语.md` §1 |
| 载荷 | 一次方法调用或一条事件里携带的数据本体，单位是字节 | `docs/ling/01-需求规格.md` §4.1 |
