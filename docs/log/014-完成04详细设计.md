## 三处跨文档冲突，都在写的过程中被发现

### 一、`plan.step` 的字段名两套

`01` 的 LING-REQ-050 要求 `plan_id`、`step`、`action`、`plugin`、`ok`、`error`；而 `04/01` 初稿写的是 `step_index`、`result`、`error_code`。

字段名进了协议就是契约，两套并存等于没有契约。处理：以 `01` 为准，统一为 `plan_id`、`step`、`step_total`、`action`、`plugin`、`ok`、`error`，回改 `04/01` §6.4 两版，并在 `04/04` 的变更记录里写明这次统一。

### 二、管理端口默认值 7900 与 7950 并存

`01` 的 LING-REQ-069 写 7900，`00` 的术语表写 7950。处理：以需求为准，`00` 两版改为 7900。

这类错误只靠人眼很难发现，因为它不影响阅读，只影响实现。

### 三、子命令表漏了两个命令

`01` 的 LING-REQ-071 列了十一个子命令，但 LING-REQ-076 要求 `doctor`、LING-REQ-077 要求 `logs`——两个命令有需求却不在列表里。

处理：`01` 两版的 071 补上 `logs` 与 `doctor`，变成十三个。

## 写文档时定下的实现级判断

## 新增的工具

`other/tools/check_docs.py`：一次校验四类问题。

| 检查 | 说明 |
|---|---|
| 两版标题对应 | 详细版与简版去掉首行 H1 后逐条比对 |
| 表格列数 | 同一表格块内竖线数必须一致，防止渲染错乱 |
| 禁用词 | 含「列举未尽」的「等」专查 |
| 乱码 | 检测替换字符 |

三处豁免：`docs/log/` 下的历史记录不查禁用词（日志只增不改）；含「禁用词」「禁令」「替换办法」的行是元引用；一行出现四个以上禁用词视为清单本身。
