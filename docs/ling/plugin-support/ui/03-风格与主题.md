# ling plugin-support/ui 03 风格与主题

> 状态：初定 | 最后更新：2026-11-02
> 依据：`docs/ling/plugin-support/ui/00-总览与约定.md` §3；`docs/ling/builtin-plugins/core-ui/04-详细设计/04-设计令牌与主题.md` §1 至 §6

本文回答：面板怎么跟外壳长得一样、主题换了怎么跟着变、哪些颜色不能自己定。

---

## 1. 一条硬规则

**界面里的颜色、字号、间距、圆角，全部引用 `--ling-*` 变量，不写具体值。**

```css
/* 对 */
body { background: var(--ling-bg); color: var(--ling-text); font-size: var(--ling-fs-md); }

/* 错：切到暗色后这块仍是白的 */
body { background: #ffffff; color: #1f2328; font-size: 13px; }
```

判断自己有没有违规，只用一招：**把界面切到暗色，如果面板里有一块仍然是白的，那块就是写死了。**

这条不是风格洁癖。core-ui 的主题就是「令牌的一套取值」，换主题等于换这套值；面板不引用令牌，就收不到这次变化，结果是一半亮一半暗，比统一不跟随更难看。

## 2. 令牌清单

26 个，分四组。取值不在这里重复，见 `docs/ling/builtin-plugins/core-ui/04-详细设计/04-设计令牌与主题.md` §2；运行时用下文的 `theme.css` 拿到当前值。

### 2.1 颜色（14 个）

| 令牌 | 用在哪 |
|---|---|
| `--ling-bg` | 主背景 |
| `--ling-bg-raised` | 浮起面：卡片、弹窗、列表项悬停底 |
| `--ling-bg-sunken` | 下沉面：输入框、代码块、次级区块 |
| `--ling-text` | 正文 |
| `--ling-text-dim` | 次要文字：说明、计数、占位符 |
| `--ling-text-invert` | 深色块上的文字 |
| `--ling-border` | 普通边框、分隔线 |
| `--ling-border-strong` | 强调边框：输入框、表格头 |
| `--ling-accent` | 主色：主按钮、选中项、进度条 |
| `--ling-accent-hover` | 主色悬停 |
| `--ling-accent-fg` | 主色块上的文字 |
| `--ling-ok` | 成功、已启用 |
| `--ling-warn` | 警告 |
| `--ling-danger` | 危险、失败、删除 |

提示条与标签的浅底色没有对应令牌，用 `color-mix` 现算，避免为四种语义各配一个底色：

```css
.notice-ok   { background: color-mix(in srgb, var(--ling-ok) 12%, var(--ling-bg)); }
.tag-danger  { color: var(--ling-danger); background: color-mix(in srgb, var(--ling-danger) 10%, var(--ling-bg)); }
```

### 2.2 字号（4 个）

| 令牌 | 用在哪 |
|---|---|
| `--ling-fs-sm` | 次要说明、表格辅助列 |
| `--ling-fs-md` | 正文默认 |
| `--ling-fs-lg` | 小标题、区块标题 |
| `--ling-fs-xl` | 页面标题 |

### 2.3 间距（5 个）

`--ling-sp-1` 至 `--ling-sp-5`，从紧到松。用于内外边距与元素间距，不要写 `padding: 13px` 这类自由值。

### 2.4 形状（3 个）

| 令牌 | 用在哪 |
|---|---|
| `--ling-radius` | 外层容器、弹窗 |
| `--ling-radius-sm` | 按钮、输入框、标签 |
| `--ling-shadow` | 浮起面的投影 |

## 3. 两种引入方式

### 3.1 引 `theme.css`（推荐）

```html
<link rel="stylesheet" href="/api/ui/theme.css">
<style>
  body { background: var(--ling-bg); color: var(--ling-text);
         font-size: var(--ling-fs-md); padding: var(--ling-sp-4); }
</style>
```

| 项 | 说明 |
|---|---|
| 地址 | `/api/ui/theme.css`，免 token，任何面板都能引 |
| 内容 | 三段：`:root` 取当前主题（首屏直接可用），`:root[data-theme="light"]` 与 `:root[data-theme="dark"]` 各 26 个令牌；面板显式切换时改 `<html data-theme>` |
| 顺序 | `<link>` 必须放在面板自己的样式之前，否则同优先级规则会按出现顺序覆盖 |
| 缓存 | `no-store`，每次取最新 |

三段都给的好处：首屏不用等消息就能上色；切主题时面板只需改 `<html data-theme>`，不必重新请求样式表，不会白闪。

### 3.2 用 `init` 里的 `tokens`

不想多一次请求的面板，可以从 `init` 消息里取：

```js
for (const [k, v] of Object.entries(m.tokens)) {
  document.documentElement.style.setProperty(k, v);
}
```

代价是首次渲染前拿不到值，所以骨架样式里仍要给令牌写一个兜底（例如 `var(--ling-bg, #ffffff)`），或者先隐藏内容等 `init`。

两种方式选一种，不要混用。混用后切换主题会出现「一部分键被覆盖、一部分没有被覆盖」。

## 4. 主题切换后要做什么

| 如果你用的是 | 收到 `theme` 后做 |
|---|---|
| `theme.css` | 把 `theme` 值写到 `<html data-theme>` 上 |
| `init` 的 `tokens` | 逐个 `setProperty` 覆盖 |

要求 300 毫秒内完成。另外两条：

| 要求 | 原因 |
|---|---|
| 不要重新加载整个页面 | 会丢掉面板状态，用户看到闪一下 |
| 不要只改一半 | 例如只改背景不改文字，暗色下会变成白底白字 |

## 5. 品牌色与例外

面板可以有品牌色（图标、进度、图表系列），但边界是固定的：

| 允许自己定 | 必须取令牌 |
|---|---|
| 图标颜色、品牌强调色、图表系列色 | 背景、正文文字、次要文字、边框、分隔线 |
| 插件 logo 里的固有颜色 | 成功、警告、危险的语义色 |
| —— | 按钮的主色与悬停色（`--ling-accent`、`--ling-accent-hover`） |

理由：品牌色是插件的标识，用户期望它稳定；而背景与文字是界面的公共部分，必须跟外壳一致，否则切主题就破相。

## 6. 尺寸与密度

| 项 | 约定 |
|---|---|
| 正文字号 | `--ling-fs-md`，不要用浏览器默认的 16px |
| 表格与列表行高 | 不低于 24 像素，文字用 `--ling-fs-sm` 时不小于 20 像素 |
| 焦点可见 | 用 `outline: 2px solid var(--ling-accent)` 加 `outline-offset: 2px`，不要 `outline: none`（令牌表里没有 `--ling-focus`，焦点色与主色共用一档） |
| 字体族 | 不指定，沿用宿主的系统栈 |

`outline: none` 会让键盘用户找不到焦点在哪，这是无障碍的硬要求，不是风格问题。

## 7. 自检清单

- [ ] 样式里没有 `#` 开头的颜色字面量（品牌色与 `:root` 兜底除外）
- [ ] 没有 `px` 写死的字号与间距
- [ ] 切到暗色后，面板里没有残留的白底块或黑字
- [ ] 切换主题时页面没有刷新，300 毫秒内完成
- [ ] 键盘 Tab 能看到焦点框
- [ ] 用 `theme.css` 与用 `tokens` 只选了一种
