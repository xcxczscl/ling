## 1. 消息概览

| 种类 | 方向 | 什么时候 | 关键字段 |
|---|---|---|---|
| `init` | 外壳 → 面板 | 网页加载完成后，只发一次 | `v`、`pluginId`、`title`、`theme`、`tokens` |
| `call` | 面板 → 外壳 | 要调自己的方法 | `id`、`method`、`params` |
| `result` | 外壳 → 面板 | 每条 `call` 与 `drag` 的回复 | `id`、`ok`、`result` 或 `error` |
| `theme` | 外壳 → 面板 | 用户换主题 | `theme`、`tokens` |
| `event` | 外壳 → 面板 | 外壳级手势与将来的推送 | `name`、`data` |
| `drag` | 面板 → 外壳 | 面板内开始一次拖动 | `id`、`kind`、`payload` |
| `shutdown` | 外壳 → 面板 | 面板即将被移除 | `reason` |

面板只能发 `call` 与 `drag`，发别的种类会被丢弃并记 warn。发消息的 `targetOrigin` 固定写 `"*"`，安全性由外壳校验收消息来源保证。

## 2. `init`

```json
{"type":"init","v":1,"pluginId":"resources-manager","title":"资源管理",
 "theme":"dark","tokens":{"--ling-bg":"#1b1b1d"}}
```

| 字段 | 用处 |
|---|---|
| `v` | 协议版本，当前 `1` |
| `pluginId` | 拼方法前缀 |
| `title` | 与清单 `[ui].title` 相同 |
| `theme` | `light` 或 `dark` |
| `tokens` | 当前主题的令牌取值 |

三条要求：`init` 之前不渲染内容（早发的 `call` 回 `E_UI_NOT_READY`）；`init` 只来一次；可以先画骨架避免长时间空白。

## 3. `call` 与 `result`

```json
{"type":"call","id":7,"method":"resources-manager.scan","params":{"path":"D:/media"}}
{"type":"result","id":7,"ok":true,"result":{"files":12}}
{"type":"result","id":7,"ok":false,"error":{"code":"E_UI_FORBIDDEN","message":"面板不能调用其他插件的方法"}}
```

`error` 里 `code` 恒有，`message` 通常有，`advice` 有就显示、没有就省略，`detail` 是被调方法给出的结构化补充（如缺的字段名、越界的路径），默认折叠。

| 项 | 规定 |
|---|---|
| `id` | 正整数，面板自增，外壳原样回带，同时在途不可重复 |
| `method` | 必须带 `<pluginId>.` 前缀 |
| `params` | JSON 对象，非对象按 `{}` 处理 |
| 回复 | 每条 `call` 必有一条且仅有一条 `result` |
| 在途上限 | 单面板 16 条，第 17 条立即回 `E_UI_BUSY` |
| 超时 | 35 秒（服务端 30 秒 + 5 秒余量），超时回 `E_TIMEOUT` |
| 参数校验 | 外壳不校验内容，方法自己校验；整个请求体上限 1 MB，超出回 `E_PAYLOAD_TOO_LARGE` |

## 4. `theme`

```json
{"type":"theme","theme":"light","tokens":{"--ling-bg":"#ffffff"}}
```

收到后把 `tokens` 写到 `<html>`，或改 `<html data-theme>`，300 毫秒内完成。超时不报错，只是面板不跟随。

## 5. `event`

```json
{"type":"event","name":"drop","data":{"kind":"files","payload":{"paths":["D:/media/a.jpg"]},"from":"resources-manager"}}
```

当前只有 `drop` 一个来源。将来的推送也走这条消息，因此**遇到不认识的 `name` 要忽略，不要报错**。

## 6. `drag`

| 步骤 | 谁做 | 动作 |
|---|---|---|
| 1 | 面板 A | 按下并移动超过 5 像素时发 `{"type":"drag","id":3,"kind":"files","payload":{...}}` |
| 2 | 外壳 | 盖透明遮罩接管手势 |
| 3 | 外壳 | 松手时给落点面板 B 发 `event`，`name` 为 `drop` |
| 4 | 外壳 | 给 A 回 `result`，`ok` 为 `true` |
| 5 | 面板 B | 收到 `drop` 后调自己的方法处理 |

落点不在任何面板上时回 `ok` 为 `false`，A 应据此恢复状态。`kind` 只能取 `files` 或 `text`，其它取值外壳不接收。

## 7. `shutdown`

`reason` 四种：`closed`（用户关闭）、`disabled`（插件停用）、`uninstalled`（插件卸载）、`evicted`（超过 4 个被挤掉）。

收到后清掉定时器、移除监听、取消在途回调。这 300 毫秒内不要发新的 `call`。

## 8. 调用规则

### 8.1 只能调自己的方法

`method` 不以 `<pluginId>.` 开头时外壳直接回 `E_UI_FORBIDDEN`，请求不到服务端。要跨插件拿数据，经自己的插件方法中转，由插件之间走宿主路由。

### 8.2 身份由来源决定，不由消息内容决定

外壳按「消息从哪个 iframe 发来」认定调用方，不读消息里的 `pluginId` 或 `plugin` 字段。面板写什么名字都不影响判定，也无法冒充别人。

### 8.3 面板侧校验来源

守卫写成 `if (e.source !== window.parent) return;`。`e.origin` 不能用：面板是不透明源，它自己的 `e.origin` 恒为 `"null"`，而外壳发来的消息带的是外壳的源——拿它做白名单只会写反。

### 8.4 拿不到 token

token 只在外壳手里，面板既不需要也无法接触。不要在面板里找 token，也不要直接请求 `/api/*`。

## 9. 面板侧最小实现

```js
let pluginId = null, seq = 0;
const pending = new Map();

window.addEventListener("message", (e) => {
  if (e.source !== window.parent) return;
  const m = e.data;
  if (!m || typeof m.type !== "string") return;
  switch (m.type) {
    case "init": pluginId = m.pluginId; applyTheme(m.theme, m.tokens); render(); break;
    case "theme": applyTheme(m.theme, m.tokens); break;
    case "result": { const cb = pending.get(m.id); if (cb) { pending.delete(m.id); cb(m); } break; }
    case "event": if (m.name === "drop") onDrop(m.data); break;
    case "shutdown": cleanup(); break;
  }
});

function call(method, params = {}) {
  return new Promise((resolve, reject) => {
    const id = ++seq;
    pending.set(id, (m) => (m.ok ? resolve(m.result) : reject(m.error)));
    parent.postMessage({ type: "call", id, method, params }, "*");
  });
}
```

`applyTheme`、`render`、`onDrop`、`cleanup` 由插件实现，`cleanup` 里清掉全部定时器与监听。

## 10. 常见错误

| 现象 | 原因 |
|---|---|
| 首次调用回 `E_UI_NOT_READY` | `init` 之前发了 `call` |
| 一直 `E_UI_FORBIDDEN` | `method` 没带自己前缀，或调了别的插件的方法 |
| 偶发 `E_UI_BUSY` | 并发超过 16 条，检查循环里发请求 |
| 35 秒后 `E_TIMEOUT` | 方法本身慢，面板要显示「处理中」并允许取消 |
| 收不到 `result` | `id` 不是正整数或被复用 |
| 拖到别的面板没反应 | 对方没监听 `drop`，或落点不在任何面板上 |
| 消息里带 `pluginId` 仍被拒 | 外壳不看该字段 |
