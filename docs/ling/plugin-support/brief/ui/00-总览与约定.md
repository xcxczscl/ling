## 3. 契约总览

| # | 要求 | 不遵守会怎样 | 细则 |
|---|---|---|---|
| 1 | 清单带 `[ui]` 段且 `capabilities` 含 `ui` | 装载失败，`E_UI_PANEL_DECL` | `01` §1 |
| 2 | `entry` 指向 `ui/` 下的 `.html` | 装载失败或 `E_UI_PANEL_NOTFOUND` | `01` §1、§2 |
| 3 | 只调自己命名空间下的方法 | `E_UI_FORBIDDEN` | `02` §8 |
| 4 | 收到 `init` 后再渲染、再发 `call` | 首屏白闪；早发的调用被丢弃 | `02` §2 |
| 5 | 颜色与尺度只取 `--ling-*` | 切主题不跟随 | `03` §1 |
| 6 | 收到 `theme` 后 300 毫秒内切换 | 外壳变了、面板没变 | `03` §4 |
| 7 | 收到 `shutdown` 后停掉定时器与监听 | 移除后仍在跑，白耗 CPU | `02` §7 |
| 8 | 禁止自己起 HTTP 服务 | 装不进功能区，主题机制失效 | `01` §4 |
| 9 | 禁止 `fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`，禁用 `localStorage` | 浏览器拦或抛错 | `01` §5 |
| 10 | 禁止依赖 token，禁止靠自报 `pluginId` 取得权限 | 自报无效，身份按 iframe 来源算 | `02` §8 |

`01`、`02`、`03` 指同目录的 `01-面板声明与资源.md`、`02-消息与调用.md`、`03-风格与主题.md`。

## 4. 版本与兼容

| 项 | 规定 |
|---|---|
| 契约适用版本 | core-ui 1.1.0 及以后，当前对应 1.1.0-b1 |
| 消息协议版本 | `init` 的 `v` 为 `1` |
| 宿主没装 core-ui | 插件照常装载与调用，没有界面（`CUI-REQ-055`），插件不得因此报错 |
| 宿主版本较旧 | `[ui]` 段被忽略，装载成功、无界面 |
| core-ui 卸载后重装 | 入口恢复，不自动打开面板（`CUI-REQ-032`） |

`[ui]` 段是可选增强，不是运行前提；方法层要能独立工作。
