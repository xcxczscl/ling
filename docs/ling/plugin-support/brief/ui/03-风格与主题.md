## 1. 一条硬规则

界面里的颜色、字号、间距、圆角，全部引用 `--ling-*` 变量，不写具体值。

```css
/* 对 */  body { background: var(--ling-bg); color: var(--ling-text); font-size: var(--ling-fs-md); }
/* 错 */  body { background: #ffffff; color: #1f2328; font-size: 13px; }
```

自检方法：切到暗色，面板里仍有白块的地方就是写死了。

## 2. 令牌清单

26 个，分四组。取值见 `docs/ling/builtin-plugins/core-ui/04-详细设计/04-设计令牌与主题.md` §2，运行时经 `theme.css` 获取。

### 2.1 颜色（14 个）

| 令牌 | 用在哪 |
|---|---|
| `--ling-bg` | 主背景 |
| `--ling-bg-raised` | 浮起面：卡片、弹窗 |
| `--ling-bg-sunken` | 下沉面：输入框、代码块 |
| `--ling-text` | 正文 |
| `--ling-text-dim` | 次要文字 |
| `--ling-text-invert` | 深色块上的文字 |
| `--ling-border` | 普通边框、分隔线 |
| `--ling-border-strong` | 强调边框 |
| `--ling-accent` | 主色 |
| `--ling-accent-hover` | 主色悬停 |
| `--ling-accent-fg` | 主色块上的文字 |
| `--ling-ok` | 成功 |
| `--ling-warn` | 警告 |
| `--ling-danger` | 危险、失败 |

浅底色不设令牌，用 `color-mix` 现算：`color-mix(in srgb, var(--ling-ok) 12%, var(--ling-bg))`。

### 2.2 字号（4 个）

`--ling-fs-sm` 次要说明、`--ling-fs-md` 正文默认、`--ling-fs-lg` 小标题、`--ling-fs-xl` 页面标题。

### 2.3 间距（5 个）

`--ling-sp-1` 至 `--ling-sp-5`，从紧到松，用于内外边距与元素间距。

### 2.4 形状（3 个）

`--ling-radius` 外层容器、`--ling-radius-sm` 按钮与输入框、`--ling-shadow` 浮起面投影。

## 3. 两种引入方式

### 3.1 引 `theme.css`（推荐）

```html
<link rel="stylesheet" href="/api/ui/theme.css">
```

地址免 token；内容是亮暗两套取值，切主题只需改 `<html data-theme>`；`no-store` 不缓存；`<link>` 必须放在面板自己的样式之前。

### 3.2 用 `init` 里的 `tokens`

```js
for (const [k, v] of Object.entries(m.tokens)) document.documentElement.style.setProperty(k, v);
```

代价是首屏渲染前拿不到值，骨架样式要给兜底。两种方式只选一种，不要混用。

## 4. 主题切换后要做什么

| 如果你用的是 | 收到 `theme` 后做 |
|---|---|
| `theme.css` | 写 `<html data-theme>` |
| `init` 的 `tokens` | 逐个 `setProperty` |

300 毫秒内完成；不整页刷新；不改一半留一半。

## 5. 品牌色与例外

| 允许自己定 | 必须取令牌 |
|---|---|
| 图标颜色、品牌强调色、图表系列色 | 背景、正文与次要文字、边框、分隔线 |
| 插件 logo 的固有颜色 | 成功、警告、危险的语义色 |
| —— | 按钮主色与悬停色 |

## 6. 尺寸与密度

正文字号用 `--ling-fs-md`；列表行高不低于 24 像素；焦点用 `outline: 2px solid var(--ling-accent)`，禁止 `outline: none`；不指定字体族。

## 7. 自检清单

- [ ] 没有 `#` 颜色字面量（品牌色与 `:root` 兜底除外）
- [ ] 没有写死的字号与间距
- [ ] 切到暗色后无残留白块或黑字
- [ ] 切换主题不刷新页面，300 毫秒内完成
- [ ] 键盘 Tab 能看到焦点框
- [ ] `theme.css` 与 `tokens` 只选了一种
