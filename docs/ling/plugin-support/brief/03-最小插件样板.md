# ling 插件支持 03 最小插件样板

> 状态：已定稿 | 最后更新：2026-11-03
> 依据：`docs/ling/plugin-support/03-最小插件样板.md`

本文是 `docs/ling/plugin-support/03-最小插件样板.md` 的简要版，只留可照抄的骨架。

## 1. 目录与清单

```
plugins/demo-a/
├── plugin.toml
└── demo_a.cpp
```

```toml
id = "demo-a"
version = "1.0.0"
api = "1"
name = "示例插件 A"
description = "最小可运行插件"
capabilities = []
```

## 2. 入口函数

```cpp
#include "ling/plugin_api.h"

namespace {

int32_t on_ping(void* handler_ctx, const uint8_t* args, size_t args_len,
                uint8_t** out, size_t* out_len) {
    static const char kPong[] = "pong";
    *out_len = sizeof(kPong) - 1;
    *out = reinterpret_cast<uint8_t*>(const_cast<char*>(kPong));
    return 0;
}

}  // namespace

LING_PLUGIN_EXPORT int32_t ling_plugin_entry(const ling_host_api* host,
                                             ling_plugin_descriptor* out_desc,
                                             void** out_plugin) {
    void* ctx = host->context_alloc("demo-a", 0);
    const int32_t code = host->register_method(
        ctx, "demo-a.ping", reinterpret_cast<void*>(&on_ping), nullptr, 0);
    if (code != 0) {
        return 3;
    }
    out_desc->abi_version = LING_ABI_VERSION;
    out_desc->plugin_id = "demo-a";
    out_desc->plugin_version = "1.0.0";
    out_desc->api = "1";
    *out_plugin = ctx;
    return 0;
}
```

要点：方法名必须带 `demo-a.` 前缀；导出符号是 `ling_plugin_entry`（`LING_PLUGIN_EXPORT` 在 `plugin_api.h` 里按平台展开）；返回的缓冲区由插件申请、插件释放。没有 `sdk.hpp` 之类的封装，直接手写。

## 3. 构建

在 `plugins/CMakeLists.txt` 加一行：

```cmake
add_ling_plugin(demo-a)
```

该宏自动做四件事：套用统一选项、命名产物为 `<编号>.dll` 或 `.so`、复制到 `run/<preset>/plugins/demo-a/`、同时复制 `plugin.toml`。

插件作者不写编译选项。

## 4. 安装与验证

```bash
./run/linux-debug/ling serve --data-dir ./run/linux-debug/data &      # [未验证]
./run/linux-debug/ling install ./run/linux-debug/plugins/demo-a --data-dir ./run/linux-debug/data  # [未验证]
./run/linux-debug/ling plugins --data-dir ./run/linux-debug/data      # [未验证] 应为 activated
ctest -R l2_call   # [未验证] 命令行没有 call 子命令；调用由调用方插件发起，期望 pong
```

## 5. 常见错误

| 现象 | 原因 |
|---|---|
| `E_MANIFEST_INVALID` 说缺字段 | 少写 `name` 或 `api` |
| `E_API_MISMATCH` | `api` 写成 `"2"` 而宿主支持 `"1"` |
| `E_NAMESPACE_VIOLATION` | 方法名写成 `ping` |
| 装载成功但 `call` 找不到 | 注册失败但没检查返回值 |
| 「不是有效的 Win32 程序」 | 插件与宿主位数不一致 |
| 崩溃在 `register_method` | `ctx` 不是宿主给的，或用了别人的 |
