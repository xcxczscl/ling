# core-settings 00 总览与边界

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-settings/00-总览与边界.md`

## 1. 一句话

给所有插件存配置的公共仓库：每个值记着谁写的、什么时候写的，卸载插件时原样退回。

## 2. 它解决什么问题

插件自己管配置会散：卸载时不知道该还原什么，用户想备份得翻每个目录，格式还不统一。收成一处之后，写一次就进账本，卸载自动还原。

## 3. 它不做什么

不做配置界面（归 `core-ui`）、不做版本迁移（归部署流程）、不解析值的内容、不加密、不管插件私有数据。

## 4. 配置与私有数据的分界

要还原、要导出、要给别人看的走配置；只属于自己的中间状态（索引、缓存、日志、大文件）写 `data/`。

## 5. 没装它的时候

`write_config` 返回 `E_PLUGIN_MISSING`；已写的配置文件原地保留；重装回来还能读到；宿主照常启动。

## 6. 谁在用

所有插件（经 `Context::write_config`）、内核（转账本条目与撤销）、`core-job`（任务定义存配置）、`core-ui`（配置页）。
