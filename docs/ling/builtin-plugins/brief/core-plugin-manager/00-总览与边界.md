# core-plugin-manager 00 总览与边界

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-plugin-manager/00-总览与边界.md`

## 1. 一句话

补命令行不做的四件事：看清依赖关系、找出白占空间的数据、一次操作一组插件、动手前先算会连带什么。

## 2. 它解决什么问题

装卸启停内核已经做了，剩下四类问题命令行答不上来：卸一个插件会连带停谁、哪些只剩 `data/` 的目录白占地方、怎么一次停一组、动手前能不能先算一遍。这些都不是「没有它宿主就不成立」的能力，所以归插件。

## 3. 它不做什么

不执行装卸启停（归内核）、不做依赖解析与调和（归内核，M3）、不做界面（归 `core-ui`）、**不删除孤儿数据**——只列，删不删由人决定。

## 4. 四项能力的成熟度

孤儿扫描与占用统计现在能用；依赖树、预演、批量都要到 M3 才能用，前提是依赖图与内核写方法。等的原因不是懒：MVP 没有依赖声明算不出树，内核写方法也只对管理端口开放。

## 5. 没装它的时候

命令行装卸不受影响，只是找不到孤儿、看不到树。它是纯便利功能，卸掉不损失核心能力。

## 6. 谁在用

主要是 `core-ui` 的插件页：依赖关系与清理建议两块由它提供数据。
