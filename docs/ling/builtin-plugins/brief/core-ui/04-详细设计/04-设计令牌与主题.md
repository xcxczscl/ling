## 1. 命名规则

前缀 `--ling-`；分组 `bg-*`、`text-*`、`border-*`、`accent-*`、`ok`、`warn`、`danger`、`fs-*`、`sp-*`、`radius-*`、`shadow`。颜色用小写六位十六进制，长度用 `px`。共 26 个，不设预留位。令牌只描述色值与尺度，不提供 `.ling-button` 这类类名。

## 2. 令牌全表

### 2.1 颜色（14 个）

| 令牌 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `--ling-bg` | 主背景 | `#ffffff` | `#1b1b1d` |
| `--ling-bg-raised` | 浮起面 | `#ffffff` | `#242427` |
| `--ling-bg-sunken` | 下沉面：侧边栏、输入框 | `#f6f7f9` | `#141416` |

| `--ling-text-dim` | 次要文字 | `#5b6472` | `#a0a7b4` |
| `--ling-text-invert` | 深色块上的文字 | `#ffffff` | `#141416` |
| `--ling-border` | 普通边框 | `#d8dde5` | `#33383f` |
| `--ling-border-strong` | 强调边框 | `#b9c0cb` | `#4a515a` |
| `--ling-accent` | 主色 | `#2f6fed` | `#6f9bff` |

提示条与标签的浅底不设令牌，用 `color-mix(in srgb, var(--ling-ok) 12%, var(--ling-bg))` 现算。

### 2.2 字号（4 个）

`--ling-fs-sm` `12px`、`--ling-fs-md` `13px`、`--ling-fs-lg` `15px`、`--ling-fs-xl` `18px`。

### 2.3 间距（5 个）

`--ling-sp-1` `4px`、`--ling-sp-2` `8px`、`--ling-sp-3` `12px`、`--ling-sp-4` `16px`、`--ling-sp-5` `24px`。

### 2.4 形状（3 个）

`--ling-radius` `8px`、`--ling-radius-sm` `4px`、`--ling-shadow` 亮色 `0 1px 2px rgba(0,0,0,0.06)` / 暗色 `0 1px 2px rgba(0,0,0,0.4)`。

14 + 4 + 5 + 3 = 26。

## 3. 主题定义

```css
:root { --ling-bg:#ffffff; … 26 个令牌 … }
:root[data-theme="dark"] { --ling-bg:#1b1b1d; … 颜色与阴影的 15 个替换 … }
```

两套之间只有颜色与阴影不同；字号、间距、圆角不随主题变，否则切换时布局会跳。

## 4. `theme.css` 接口

`GET /api/ui/theme.css` 免 token，返回两套完整取值：

| 项 | 规定 |
|---|---|
| 内容 | 三段：`:root` 默认块取当前主题；两个 `[data-theme]` 块各给一套全量 |
| `Cache-Control` | `no-store` |
| 生成方式 | 从同一份令牌表拼字符串 |

三段的作用：`:root` 让还没有 `data-theme` 的面板首屏就是对的颜色（不白闪）；两个 `[data-theme]` 块让面板收到 `theme` 后只改属性，不必重载 CSS。

## 5. 主题切换

### 5.1 时序

```
1. 点暗色预览卡
2. 外壳立刻给自己设 data-theme="dark"     ← 乐观更新
3. 向每个面板 postMessage {type:"theme"}
4. POST /api/config.set {key:"core-ui.theme", value:"dark"}
5. 成功静默；失败回滚 data-theme 并广播旧值，提示「主题没能保存」
```

### 5.2 启动时读主题

`config.get` 拿 `light` 或 `dark` 设到 `<html>`；键不存在用 `light`，不回写。默认 HTML 写 `data-theme="light"`，暗色用户会看到一次极短的亮色闪动。

### 5.3 跟随系统

1.1.0 不做：要监听 `prefers-color-scheme`，还要多一个三态配置（亮 / 暗 / 跟随系统）。

## 6. 面板怎么用

### 6.1 推荐写法

```html
<link rel="stylesheet" href="/api/ui/theme.css">
<style> body { background: var(--ling-bg); color: var(--ling-text); } </style>
```

`<link>` 必须在面板自己的样式之前。

### 6.2 另一种写法：用 `init` 里的 `tokens`

逐个 `document.documentElement.style.setProperty(k, v)`。代价是 `init` 到达前首屏无色，会白闪。

### 6.3 切主题后要做什么

用 `<link>` 的改 `<html data-theme>`；用 `tokens` 的逐个覆盖变量。都要在 300 毫秒内完成。

### 6.4 面板自己的颜色

品牌色、图标色可以自带，**背景、文字、边框、语义色必须取令牌**。判断标准：切到暗色后仍有一块白，那块就是写死了。

## 7. 校验

### 7.1 硬性检查

| 检查 | 不通过 |
|---|---|
| 外壳样式表里十六进制只出现在两套 `:root` 块内 | 构建失败 |
| 亮色块是完整 26 个，暗色块是 15 个子集（14 色 + 阴影）（只对 `shell.css`；`theme.css` 三块都是全量） | 构建失败 |
| 同一令牌两套取值类型一致 | 构建失败 |
| 对比度按 WCAG AA 4.5:1 核对四个组合 | 人工核对 |

对比度现状：`text`/`bg` 亮 15.9 : 1、暗 13.2 : 1；`text-dim`/`bg` 亮 6.1 : 1、暗 7.4 : 1；`accent-fg`/`accent` 亮 4.6 : 1、暗 8.9 : 1；`danger`/`bg` 亮 4.7 : 1、暗 5.9 : 1。亮色的 `accent-fg`/`accent` 刚好过线，改主色时必须重算。

### 7.2 禁止项

外壳里不写死颜色；面板不用 `!important` 覆盖令牌；不引用 `--ling-` 之外的变量作颜色；令牌里不放 `font-family`；不新增只有暗色需要的令牌。

唯一允许的字面量是对话框遮罩 `rgb(0 0 0 / 32%)` 与阴影里的 `rgba(0,0,0,…)`，扫描脚本对这两处放行。
