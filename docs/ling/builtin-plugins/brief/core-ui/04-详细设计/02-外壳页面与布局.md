## 1. 文档骨架

单页应用，一份 HTML 三块区域：

```html
<div id="app">
  <aside id="sidebar">…</aside>
  <main id="workspace"><div id="panel-area"></div><div id="empty-state"></div></main>
  <section id="settings" hidden>…</section>
</div>
```

| 块 | 显示条件 | 与谁互斥 |
|---|---|---|
| `#panel-area` + `#empty-state` | 平时 | 有面板时隐藏空状态 |
| `#settings` | 点「设置」后 | 盖住 `#workspace`，侧边栏不消失 |
| `#sidebar` | 始终 | 无 |

`#settings` 出现时不卸载面板，iframe 留在 DOM 里被盖住。

## 2. 侧边栏

### 2.1 入口怎么生成

调 `POST /api/panels`，按 `id` 升序生成按钮，含图标与名称。

| 规则 | 说明 |
|---|---|
| 排序 | 按插件 `id` 升序 |
| 图标 | 有 `icon` 显示，没有显示首字 |
| 停用的插件 | 仍显示、文字变淡，点击后显示「插件已停用」与「启用」 |
| 没有 `[ui]` 的插件 | 不显示 |
| 数量 | 超过 12 个时内部滚动 |

### 2.2 收缩

展开 188 像素，收起 48 像素；窗口宽度小于 900 像素时自动收起；写 `core-ui.sidebar`。

### 2.3 底部

两行：`● 宿主运行中` 与 `设置`。状态每 5 秒探一次，断了变红显示「ling 没有响应」。没有独立首栏。

## 3. 功能区

### 3.1 面板外框

| 项 | 规定 |
|---|---|
| 标题条高度 | 32 像素 |
| 标题 | 取 `[ui].title`，过长省略号，悬停显示全名 |
| 关闭钮 | 只关面板，不卸载插件 |
| 边框与圆角 | 取 `--ling-border`、`--ling-radius` |
| 标题条上没有拖动柄 | 布局不支持自由拖动，留把手只会误导 |

```html
<iframe src="/panel/<id>/<entry 去 ui/ 前缀>"
        sandbox="allow-scripts allow-popups allow-downloads"
        referrerpolicy="no-referrer"></iframe>
```

`<entry 去 ui/ 前缀>` 按插件自己声明的 `[ui].entry` 换算，不是固定 `index.html`。

不给 `allow-same-origin`，面板因此是不透明源。

### 3.2 打开与关闭

| 动作 | 行为 |
|---|---|
| 未打开时点入口 | 追加到末尾 |
| 已打开时点入口 | 不重复打开，闪一下外框 |
| 点关闭钮 | 移除面板，入口保留 |
| 已开 4 个时开新的 | 关掉最早打开的，提示「已关闭较早打开的：<名称>」 |
| 插件停用或卸载 | 关闭该面板 |

上限 4 个：5 个以上每个不足 240 像素。

### 3.3 宽度分配与分隔条

| 项 | 规定 |
|---|---|
| 默认宽度 | 平均分配：1 个占满、2 个各 50%、3 个各 33.33%、4 个各 25% |
| 分隔条 | 8 像素，中间 1 像素竖线 |
| 拖动 | 相邻两个宽度按像素互补变化，其余不变 |
| 最小宽度 | 每个面板 240 像素 |
| 持久化 | 释放 300 毫秒后写 `core-ui.layout` |
| 双击分隔条 | 恢复平均分配 |

### 3.4 空状态

没有带 `[ui]` 的插件：「当前没有带界面的插件。可以在设置 → 插件里安装。」有但没打开：「从左侧选一个插件开始。」恢复失败：「上次打开的面板没能恢复，请重新选择。」

## 4. 设置二级界面

### 4.1 结构

左侧六个页签（插件、日志、配置、任务、外观、关于），右侧内容。点侧边栏任一插件入口即离开设置，功能区回到原面板集合。页签记在 `location.hash`，刷新后回到同一页。

### 4.2 插件页

列为插件名、版本、状态（彩色圆点 + 文字）、类型、有面板标签、操作。顶部有安装、筛选、搜索。

| 操作 | 文案 |
|---|---|
| 停用 | 「停用 demo-a？它会停止工作，数据保留。」有下游时追加「同时会停用 demo-b、demo-c。」 |
| 卸载（保留数据） | 「卸载 demo-a？它的数据会留在 `<路径>`，以后装回来还能用。」 |
| 卸载（删数据） | 「卸载 demo-a 并删除它的全部数据？**这一步不能撤销。**」按钮写「卸载并删除」 |

危险按钮放右侧、红底文字，默认焦点在主按钮。「启动失败」的行可展开显示 `last_error` 与「看日志」。

### 4.3 日志页

自动刷新默认开、间隔 2 秒、只拉 200 行；滚到顶部再拉 200 行；DOM 上限 5000 行；只染行首级别标签。

### 4.4 配置页

布尔给开关、数字给数字框、字符串给单行（超过 80 字符用多行）、对象与数组给 JSON 文本框。改完立即保存；失败时标红、显示原因、**内容不清空**；成功闪「已保存」2 秒。

### 4.5 任务页

列为名字、时间表（cron 原文 + 人话解释）、目标方法、上次触发、操作。新增表单含名字、cron、目标方法、参数、补跑开关；cron 下方实时显示下次触发时间，写错提示「『时』段取值 25 超出范围 0 至 23」。

### 4.6 外观页

| 项 | 控件 | 写哪个键 |
|---|---|---|
| 主题 | 两张预览卡（亮 / 暗），点一下立即生效 | `core-ui.theme` |
| 侧边栏默认 | 开关 | `core-ui.sidebar_default`（当前展开状态另存 `core-ui.sidebar`） |

预览卡用令牌自身的颜色画，切暗色时两张卡一起变。

### 4.7 关于页

| 项 | 控件 |
|---|---|
| 版本 | 只读，宿主与界面各一行 |
| 界面地址 | 只读，可复制 |
| 数据目录 | 只读 |
| 关闭窗口时 | 单选，写 `core-ui.close_behavior` |
| 退出 ling | 按钮，二次确认 |
| 设计令牌 | 折叠区，列出当前主题的 26 个令牌 |

`stop-host` 文案写清后果：「关掉界面时同时退出 ling，正在跑的定时任务会中断」。

## 5. 通用规矩

每个操作有反馈；失败不吞消息；危险操作二次确认；长操作有进度；不弹窗套弹窗；Tab 走完所有可点元素、Esc 关确认框；只显示中文；颜色只取令牌。

## 6. 键盘与可访问性

| 键 | 动作 |
|---|---|
| `Tab` / `Shift+Tab` | 在侧边栏、外框、设置控件间移动 |
| `Alt+1` 至 `Alt+4` | 切到第 1 至第 4 个面板外框 |
| `Esc` | 关确认框 |
| `Enter` | 确认对话框主按钮 |
| `Ctrl+F` | 不拦截 |

焦点进入 iframe 后由面板自己管，外壳不劫持（跨源也做不到）。
