# core-ui 03 页面与交互

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-ui/03-页面与交互.md`

## 1. 整体结构

单页应用：左边固定导航（插件、日志、配置、任务），右边内容区，顶部一行显示版本、宿主状态、刷新。不引前端框架——四个视图、十来个接口，原生 DOM 与 `fetch` 就够用。

## 2. 插件视图

### 2.1 列表

一行一个插件：名字、版本、状态（彩色圆点加文字，色盲靠文字也能分辨）、类型、操作。

### 2.2 顶部操作

安装、筛选（全部 / 在用 / 停用 / 失败）、按名字搜索。

### 2.3 危险操作的确认

停用要说清「会停什么、数据保留」；卸载分「保留数据」与「删除数据」两条，后者按钮写「卸载并删除」而不是「确定」，默认焦点在主按钮上。

### 2.4 启动失败的条目

展开显示原因与「看日志」按钮。

## 3. 日志视图

### 3.1 布局

上面一行选择器（插件、级别、自动刷新、清屏），下面是日志区。级别只给行首标签上色，不整行染色。

### 3.2 刷新与加载

自动刷新默认开、2 秒一次、只拉 200 行；往上滚加载更早的；超过 5000 行从 DOM 里删最早的。

### 3.3 空状态

没选插件时提示选一个；选了没日志时提示「还没写过日志」。

## 4. 配置视图

### 4.1 结构

左边选插件，右边按类型给控件：布尔开关、数字输入、字符串输入、对象用 JSON 文本框并校验。

### 4.2 保存

改完立即保存；失败时标红并说明原因，**内容不清空**；成功闪一条提示。

### 4.3 只读提示

`core-settings` 没装时整页显示说明，不报错也不空白。

## 5. 任务视图

### 5.1 列表

名字、时间表（cron 原文加一句人话解释）、目标方法、上次触发、操作。

### 5.2 新增任务

表单含 cron 与目标方法；cron 下方实时显示下次触发时间，写错时指出哪一段超范围。

### 5.3 空状态

没有任务时给一句提示与一个「新增」按钮。

## 6. 通用规矩

每个操作都有反馈；失败必须显示出来；危险操作二次确认；长操作有进度；不弹窗套弹窗；Tab 能走完所有可点元素；只显示中文。

## 7. 与用例的对应

`CU-01` 至 `CU-11` 落在四个视图里；`CU-12` 至 `CU-15` 属于服务端与部署，不在界面上。
