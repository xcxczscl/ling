## 1. 发布产物

`core-ui` 不单独发版，跟宿主一起打包：

| | 便携版 | 安装包 |
|---|---|---|
| `webui` | `ling-<宿主版本>-win64-webui.zip` | `ling-<宿主版本>-win64-webui-setup.exe` |
| `desktop` | `ling-<宿主版本>-win64-desktop.zip` | `ling-<宿主版本>-win64-desktop-setup.exe` |

`webui-*` 用 `LING_CORE_UI_DESKTOP=OFF`、控制台子系统（就绪行走标准输出）；`desktop-*` 用 `ON`、链 WebView2 SDK。四包差别只在 `core-ui` 的编译方式。

## 2. 版本与兼容

### 2.1 三个版本号各管什么

| 版本号 | 管什么 |
|---|---|
| 宿主版本 | 整个发行包 |
| `core-ui` 版本 | 界面进程行为；1.1.0 起含面板能力 |
| 插件 API 版本 `api` | 清单与调用协议的兼容性；本次仍为 `"1"` |

`api` 不变：1.1.0 只新增 `[ui]` 段与 `ui` 能力的含义，没改任何已有字段。

### 2.2 `[ui]` 段不单独版本化

`[ui]` 跟随 `api` 走。将来不兼容的改动随 `api` 升到 `"2"` 一起做。

### 2.3 四种组合的行为

| 插件 | `core-ui` | 行为 |
|---|---|---|
| 无 `[ui]` | 任意 | 正常，只是没有界面 |
| 有 `[ui]` | 1.1.0 及以上 | 正常，侧边栏出现入口 |
| 有 `[ui]` | 1.0.0 | 装载成功（未知段被忽略），没有界面，其他功能正常 |
| 有 `[ui]` | 未安装 | 同上 |

硬要求：**插件不得因为「面板没被显示」而报错或拒绝工作**（`CUI-REQ-055`）。

### 2.4 向后兼容的边界

新增可选字段、新增消息类型：不需要升 `api`。改字段名或语义、删除能力取值：需要升 `api`。改令牌名不升 `api`，但要在一个版本里同时提供新旧两套。

## 3. 升级

### 3.1 从 1.0.0 升到 1.1.0

关界面 → 替换 `plugins/core-ui/` 或装新版 → 重启宿主 → 打开界面确认入口。

配置不用迁移：新增的三个键读到不存在时用默认值（`light`、展开、空布局）。

### 3.2 升级后第一次打开

功能区为空（正常）；管理视图搬进了「设置」；界面是亮色（默认）。

### 3.3 插件侧要做的

已内置的四个插件不用改。将来带界面的插件：加 `[ui]` 段、`capabilities` 加 `ui`、目录加 `ui/`、首屏用 `--ling-*`。

## 4. 回滚

### 4.1 从 1.1.0 回到 1.0.0

关界面 → 换回 1.0.0 可执行文件 → 重启宿主。

1.1.0 写入的四个键在 1.0.0 里不被读取，留着无害。

### 4.2 回滚会影响什么

面板消失；界面偏好失效（重新升级后恢复）；插件本身不受影响。

### 4.3 不建议回滚的情形

已经有人用面板干活时不要回滚，否则会被当成插件坏了。要回滚就同时通知使用者。

## 5. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 8010 打开是空白 | 端口顺延，浏览器开了旧地址 | `ling open` |
| 侧边栏没有某插件 | 无 `[ui]`、缺 `ui` 能力或校验失败 | `ling plugins` + `ling logs <插件>` |
| 面板全白、外框正常 | 面板脚本报错 | `webui` 版 + DevTools 切到该 iframe |
| 「面板文件不存在」 | `entry` 路径与文件不符 | 核对 `plugin.toml`，改完重装 |
| 「面板文件读取超时」 | 磁盘慢或文件被占用 | `ling logs core-ui` |
| 切主题没反应 | `core-settings` 没启用 | 启用它 |
| 某个面板不变色 | 面板写死了颜色 | 改成 `var(--ling-*)` |
| 一直「ling 没有响应」 | 宿主在关闭，或 token 失效 | 重开界面 |
| 连续三次启动失败 | 8010 至 8099 全被占，或 token 不对 | 释放端口，看日志 |
| 面板按钮报「没有权限」 | 调了别的插件的方法 | 防护生效，改为经插件本体中转 |
| 弹「口令已变」 | 宿主重启换了 token | 从主程序重开界面 |
| `desktop` 版只开了浏览器 | 缺 WebView2 运行时，已降级 | 正常；要窗口就装运行时 |

### 5.1 常用命令

```bash
ling plugins
ling logs core-ui
ling open
curl -i http://127.0.0.1:8010/api/ui/theme.css
```

最后一条不需要 token，用来确认服务端活着。

## 6. 备份与恢复

| 键 | 丢失后的表现 |
|---|---|
| `core-ui.theme` | 回到 `light` |
| `core-ui.sidebar` | 侧边栏展开 |
| `core-ui.layout` | 不恢复上次的面板 |
| `core-ui.close_behavior` | 回到 `keep-host` |
| `core-ui.window` | 窗口开在默认位置 |

这些键随 `core-settings` 一起导出与还原。丢了不影响可用性，全部有默认值。
