# core-ui 06 安全设计

> 状态：初定 | 版本：1.1.0-b1 | 最后更新：2026-11-02
> 详细版：`docs/ling/builtin-plugins/core-ui/06-安全设计.md`

## 1. 资产与对手

### 1.1 要保护的东西

| 资产 | 被拿走会怎样 |
|---|---|
| token | 等于拿到宿主全部管理权 |
| 宿主管理权（`/api/*`） | 同上 |
| 插件数据 | 面板只能经自己的插件方法取，取到什么由该插件决定 |
| 界面完整性 | 可骗用户点「卸载并删除」 |

### 1.2 对手

有 bug 的面板、恶意的面板、本机其他进程、用户浏览的其他网站。

不设防的对手：已经能读 `session.json` 的本机进程——它拿到的权限与 core-ui 相同，这是宿主层的边界。

## 2. 三道边界

| 边界 | 守什么 | 手段 |
|---|---|---|
| 源边界 | 面板读不到外壳的东西、发不出请求 | `sandbox` 不含 `allow-same-origin`；CSP `connect-src 'none'` |
| token 边界 | 没 token 调不动 `/api/*` | bearer token；面板资源与主题样式表例外 |
| 能力边界 | 插件只能调自己命名空间 | 外壳一次、服务端一次、宿主再一次 |

## 3. 威胁清单

| 编号 | 威胁 | 缓解 | 残留 |
|---|---|---|---|
| SEC-01 | 面板关掉宿主 | 外壳与服务端双重命名空间校验 | 无 |
| SEC-02 | 面板冒充别的插件 | 按 `event.source` 查表认定调用方 | 无 |
| SEC-03 | 面板读走 token | 不透明源；token 不进消息、不进 iframe 地址 | 无 |
| SEC-04 | 面板直接请求 `/api/*` | 跨源被拦 + CSP `connect-src 'none'` | 无 |
| SEC-05 | `../` 读插件目录其他文件 | 五道路径检查 + 后缀白名单 | 无 |
| SEC-06 | 符号链接逃出 `ui/` | 解析真实路径后比对前缀 | 无 |
| SEC-07 | 别的网站 iframe 嵌入界面做点击劫持 | `X-Frame-Options: DENY` + `frame-ancestors 'none'` | 无 |
| SEC-08 | 面板发海量请求 | 在途上限 16 条，超出 `E_UI_BUSY` | 面板仍可占 CPU |
| SEC-09 | 伪造消息来源 | `source` 查表 + `origin` 只放行 `"null"` | 无 |
| SEC-10 | 插件卸载后残留面板继续调方法 | 服务端校验插件当前可用 | 无 |
| SEC-11 | 插件名注入 HTML | 标题一律 `textContent` 写入 | 无 |
| SEC-12 | 主题名注入 CSS | 主题名只接受 `light` 与 `dark` | 无 |
| SEC-13 | 面板用弹窗钓鱼 | 弹窗交系统浏览器，且弹窗无 token | 用户会被内容欺骗 |
| SEC-14 | 面板冒充系统提示 | 无技术手段，靠 §8.1 的界面约定把系统级提示与面板内容在位置上分开 | 见 §8 |

SEC-11 与 SEC-12 是「把数据当代码用」，一个在渲染层，一个在配置层。

## 4. iframe 隔离的具体取值

```html
<iframe sandbox="allow-scripts allow-popups allow-downloads"
        referrerpolicy="no-referrer"></iframe>
```

| 取值 | 给不给 | 理由 |
|---|---|---|
| `allow-scripts` | 给 | 面板要跑 JS |
| `allow-same-origin` | **不给** | 给了等于没沙箱，能读走 token |
| `allow-forms` | 不给 | 面板的 CSP 带 `form-action 'none'`，原生表单提交本来就被禁；表单交互改用 JS 加 `call` |
| `allow-popups` | 给 | 要能开外部链接 |
| `allow-downloads` | 给 | 要能导出文件 |
| `allow-modals` | 不给 | `alert` 会挡住整个界面 |
| `allow-top-navigation` | 不给 | 不能把整页导航走 |

不给 `allow-same-origin` 的连带结果：读不到 `localStorage` 与 Cookie；`fetch` 属跨源被拦；`document.domain` 抛错；`targetOrigin` 只能写 `"*"`。安全性因此改由外壳校验：身份看 `event.source` 对照表，来源只放行 `event.origin === "null"`（不透明源）。

## 5. CSP

### 5.1 外壳页面

```http
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self';
  img-src 'self' data:; connect-src 'self'; frame-src 'self'; frame-ancestors 'none';
  base-uri 'none'; form-action 'none'
X-Frame-Options: DENY
```

`frame-src 'self'` 挡住「把面板做成嵌入外部网站」；`frame-ancestors` 与 `X-Frame-Options` 一起挡点击劫持。

### 5.2 面板资源

```http
Content-Security-Policy: default-src 'self' data: blob:;
  script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline';
  connect-src 'none'; form-action 'none'; frame-ancestors 'self'
```

`'unsafe-inline'` 因为面板多半没构建链；`connect-src 'none'` 是第三重保险，即使浏览器放行跨源，面板也发不出 XHR、`fetch`、WebSocket、`EventSource`。

推送的终点是外壳，外壳再经 `postMessage` 转给面板，所以 `connect-src 'none'` 不影响将来的推送。

## 6. 认证与 token

token 只在外壳内存与 `sessionStorage`，不写 Cookie、不落盘、首次进入用完即从地址栏抹掉；面板任何位置不出现 token；免认证只有四类地址；401 提示重新打开，不自动重试；token 比较用常量时间。

## 7. 能力门禁的实现

```
面板 call(kernel.shutdown)
  ↓ 第 1 层 外壳：method 前缀必须是该 iframe 对应插件 id
  ↓ 第 2 层 服务端：plugin 与 method 前缀一致
  ↓ 第 3 层 宿主：方法存在、能力校验通过
```

第 2 层看似重复，防的是「外壳自己被绕过」，成本是一次前缀比较。`/api/<动作>` 不经第 1 层，靠 token 保证。

## 8. 残留风险

| 风险 | 说明 | 为什么不解决 |
|---|---|---|
| 本机进程可读面板代码与主题 | 静态资源免 token | 都不是秘密；要挡就得加票据机制，复杂度过高 |
| 读到 `session.json` 就能直连管理端口 | 绕过 core-ui | 属宿主能力边界 |
| 面板可显示任意内容（假警告、假更新） | 无法区分插件界面与伪装成系统的界面 | 见 §8.1 |
| 面板会拖垮整个标签页 | 取决于浏览器是否给 sandbox iframe 独立进程（Chrome 111 起默认隔离） | 要进程级隔离就得放弃 iframe |
| 拖拽 `payload` 可夹带任意文本（上限 8 KB） | 落点面板会收到不可信字符串 | 接收方自己校验，与「插件方法要校验参数」同一原则 |

### 8.1 界面约定（配合上面第三条）

系统级提示只在两处：侧边栏底部一行、功能区顶部一条临时提示。面板区域内的一切视为插件内容，默认不可信。危险操作（卸载、删数据、退出 ling）只在设置页做，不在面板里。

## 9. 编码安全清单

- `handlePanelMessage` 在任何 DOM 操作前完成 `source` 查表与 `origin` 比对
- 调用方身份只来自 iframe 映射表
- 插件提供的内容一律 `textContent`
- 主题名只接受 `light` 与 `dark`
- 面板路径过五道检查，第 4 道用真实路径
- 后缀白名单之外一律 404
- `/api/*` 除四类免认证外全校验 token
- token 比较用常量时间
- iframe `sandbox` 不含 `allow-same-origin`
- 外壳页带 CSP 与 `X-Frame-Options: DENY`；面板资源带 CSP（含 `form-action 'none'`），不设 `X-Frame-Options`
- 在途请求超 16 条立即回 `E_UI_BUSY`
- 越权与非法消息都记 warn，含插件名与方法名
