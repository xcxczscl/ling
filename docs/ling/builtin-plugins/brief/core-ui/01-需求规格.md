## 1. 需求从哪来

| 上游条目 | 本插件承担的部分 |
|---|---|
| `LING-REQ-075` | 界面不能是任何能力的唯一入口 |
| `LING-REQ-116` | 界面崩溃不影响宿主，2 秒内自动重启 |
| `LING-REQ-072` | 与命令行走同一条调用路由 |
| `LING-REQ-078` | 内置插件无特权 |
| `LING-REQ-115` | 只绑回环 |

需求编号 `CUI-REQ-###`，代号 `CUI` 已登记在 `docs/common/01-术语表.md`。

## 2. 功能需求

### 2.1 界面骨架

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-001` | 侧边栏列出全部带面板的插件，底部固定「设置」 | 3 个带 `[ui]` 的插件出现 3 项，按 `id` 升序；「设置」在最下 |
| `CUI-REQ-002` | 侧边栏可收起与展开，状态写入 `core-ui.sidebar` | 收起后功能区占满；重启保持 |
| `CUI-REQ-003` | 「设置」进二级界面，含插件、日志、配置、任务、外观、关于六个页签 | 六页签都有内容，切换不刷新 |
| `CUI-REQ-004` | 功能区最多 4 个面板，横向均分，可拖分隔条 | 4 个时每个宽度为四分之一（误差 ≤ 4 像素）；拖动后相邻宽度互补 |
| `CUI-REQ-005` | 面板外框由外壳绘制，含插件名与关闭钮 | 顶部 32 像素高的条；插件网页不含它也能显示 |
| `CUI-REQ-006` | 关掉面板后入口仍在，可重新打开 | 再点该视图按 `core-ui.layout.order` 的原槽位插回，宽度不变 |
| `CUI-REQ-007` | 打开集合与各面板宽度写入 `core-ui.layout`，重启恢复 | 调宽比例后重启，两者一致 |

### 2.2 插件面板

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-010` | `[ui]` 段声明面板，字段 `entry`、`title`、可选 `icon`；`entry` 须在 `ui/` 下且为 `.html`，`icon` 只收 `.svg`/`.png`，`title` 1 至 32 字符 | 缺必填字段、路径越界、后缀不合规、`title` 超长，四种都报 `E_UI_PANEL_DECL` 并指明是哪一项 |
| `CUI-REQ-011` | 声明 `[ui]` 的插件，`capabilities` 必须含 `ui` | 未声明 `ui` 却写 `[ui]` 段时装载失败，说明缺哪项 |
| `CUI-REQ-012` | 面板网页从插件 `ui/` 读取，由 core-ui 服务端统一发出 | 面板地址 `/panel/<id>/<entry 去 ui/ 前缀>` 返回该文件；`ui/` 之外的文件取不到 |
| `CUI-REQ-013` | 面板在 iframe 中加载，不授予同源 | 面板内 `document.domain` 抛安全错误；读不到外壳 `sessionStorage` |
| `CUI-REQ-014` | 面板只能调自己命名空间的方法 | 面板调 `kernel.shutdown` 回 `E_UI_FORBIDDEN`，宿主未退出 |
| `CUI-REQ-015` | 面板拿不到 token，不能自己发 HTTP | 面板内 `fetch("/api/plugins")` 被拒；页面源码与消息中无 token |
| `CUI-REQ-016` | 消息协议固定七种：`init`、`call`、`result`、`theme`、`event`、`drag`、`shutdown` | 逐条验：`init` 在 `load` 后到且只到一次；`call` 必回一条 `result`；`theme` 改配色；`drag` 后落点收到 `drop`；`shutdown` 后 300 毫秒内移除 |
| `CUI-REQ-017` | 入口文件缺失时预检一返回就显示原因与「重试」；从设 `src` 起 10 秒未触发 `load` 时显示「加载超时」与「重试」 | 删掉 `entry` 指向的文件，一秒内出「面板文件不存在」；让入口页卡住不触发 `load`，10 秒时出「面板加载超时」 |
| `CUI-REQ-018` | 单个面板报错或卡死不拖垮外壳与其他面板 | 一个面板死循环时，另一个仍可操作 |

### 2.3 主题与观感

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-020` | 外壳样式只引用 `--ling-*` 令牌，不写死颜色 | 颜色值只出现在令牌定义处 |
| `CUI-REQ-021` | `light`、`dark` 两套主题，存 `core-ui.theme`，切换立即生效 | 300 毫秒内外壳与已开面板变色，无需刷新 |
| `CUI-REQ-022` | 主题变化时向每个面板广播 `theme` 消息 | 面板 `data-theme` 同步更新 |
| `CUI-REQ-023` | 新面板样式表的 `:root` 默认块取当前主题，`init` 消息再带主题与令牌 | 暗色下新开面板首屏即暗色（由 `theme.css` 默认块保证），无白闪 |

### 2.4 生命周期

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-030` | 停用或卸载时面板关闭并提示；停用后入口变淡保留，卸载后入口消失 | 停用后 2 秒内面板与外框消失、入口变淡；卸载后入口消失 |
| `CUI-REQ-031` | 插件启动失败时面板显示原因与「看日志」 | 侧车连崩三次后面板显示 `last_error`，按钮跳到日志页并选中该插件 |
| `CUI-REQ-032` | 插件重新启用或重装后入口恢复，不自动开面板 | 重装后入口出现，功能区无新增面板 |
| `CUI-REQ-033` | 界面崩溃不影响宿主，2 秒内重启一次，连续三次后停止 | 强杀三次后 `ling plugins` 显示「启动失败」并附原因 |

### 2.5 管理面板

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-040` | 插件列表与 `ling plugins` 一致 | 名称、版本、状态逐条相同 |
| `CUI-REQ-041` | 安装、停用、启用、卸载；停用提示连带对象；卸载可选保留或删数据 | 停用被依赖插件出现连带清单；删数据后目录消失 |
| `CUI-REQ-042` | 日志按插件与级别筛选，2 秒自动刷新，单次渲染 200 行 | 10 万行下滚动流畅 |
| `CUI-REQ-043` | 配置按类型给控件，改完即存，失败保留输入 | 断开宿主后保存，内容不丢并显示原因 |
| `CUI-REQ-044` | 新增任务校验 cron，错误定位到段 | `0 25 * * *` 提示「『时』段取值 25 超出范围 0 至 23」 |
| `CUI-REQ-045` | 设置页有关闭行为与「退出 ling」，存 `core-ui.close_behavior` | 选 `stop-host` 后关窗，宿主 3 秒内退出 |

## 3. 非功能需求

| 编号 | 需求 | 验收标准 |
|---|---|---|
| `CUI-REQ-050` | 只监听 `127.0.0.1`，不可配置 | `netstat` 只见回环 |
| `CUI-REQ-051` | 面板资源解析结果必须落在该插件 `ui/` 目录内 | `/panel/<id>/../../plugin.toml` 返回 404 |
| `CUI-REQ-052` | 面板资源与 `theme.css` 免 token，其余 `/api/*` 必须带 token | 无 token 请求 `/api/plugins` 返回 401；面板入口返回 200 |
| `CUI-REQ-053` | 越权调用一律拒绝并记 warn，日志含来源插件与方法名 | 面板调 `kernel.shutdown` 后日志出现带插件名的 warn |
| `CUI-REQ-054` | 四个面板同时打开时内存增量不超过 200 MB | 对比打开前后工作集 |
| `CUI-REQ-055` | 没装 core-ui 时带 `[ui]` 的插件照常装载与调用 | 卸掉后装一个带 `[ui]` 的插件，装载成功且方法可调 |
| `CUI-REQ-056` | `[ui].entry` 指向的文件不存在时装载仍成功，面板显示错误态并记 warn | 删入口文件后重装，装载成功；打开面板出错误态 |

## 4. 场景

### 4.1 打开界面

`webui` 自动开浏览器到 `127.0.0.1:8010`（端口顺延时读 `ui_port`）；`desktop` 出窗口；1 秒内出内容。

### 4.2 打开一个插件的界面

侧边栏出现 `[ui].title` 一项，有 `icon` 时显示图标；点击后 2 秒内出内容；插件没起来时显示原因。

### 4.3 在插件界面里干活

调用落到该插件的方法；慢于 1 秒时面板自己显示处理中；跨插件只能经自己的插件中转；错误码与人话原因一起回给面板。

### 4.4 换主题

「设置」→「外观」切换，立即生效；已开面板跟着变，不刷新、不白闪；重启保持。

### 4.5 管理面板的原场景

列表、安装、停用、卸载、日志、配置、任务、崩溃八种场景与 1.0.0 一致，入口改为设置二级界面，对应 `CUI-REQ-040` 至 `CUI-REQ-045`、`CUI-REQ-033`。

## 5. 用例与验收标准

原有 `CU-01` 至 `CU-16` 保留含义，新增从 `CU-17` 起。

| 编号 | 场景 | 期望 | 怎么判 |
|---|---|---|---|
| CU-01 | 启动后打开界面 | 1 秒内出内容 | 计时 |
| CU-02 | 列表与命令行一致 | 条目与状态相同 | 逐条比对 |
| CU-03 | 界面装插件 | 新增且状态正确 | 命令行复核 |
| CU-04 | 装坏插件 | 人话原因，不留残件 | 目录检查 |
| CU-05 | 停用有下游的插件 | 先提示连带谁 | 对话框文案 |
| CU-06 | 卸载删数据 | 目录消失 | 文件系统 |
| CU-07 | 日志筛选 | 只剩选中级别 | 每条含对应标签 |
| CU-08 | 日志 10 万行 | 滚动不卡 | 首屏时间 |
| CU-09 | 改布尔配置 | 立即生效 | 命令行读回 |
| CU-10 | 保存失败 | 内容保留 | 断开宿主后试 |
| CU-11 | cron 写错 | 下方提示 | 文案含段名 |
| CU-12 | 强杀界面 | 2 秒内重启 | 观察进程 |
| CU-13 | 连崩三次 | 停止重启 | `ling plugins` |
| CU-14 | 别的机器访问 | 连不上 | `netstat` |
| CU-15 | 卸掉 core-ui | 命令行全可用 | 逐条跑 |
| CU-16 | 关窗选退出 | 宿主退出 | 进程检查 |
| CU-17 | 装带 `[ui]` 的插件 | 侧边栏出现入口 | 界面观察 |
| CU-18 | 点入口 | 面板 2 秒内出内容 | 计时 |
| CU-19 | 开两个面板 | 并排、可拖宽 | 宽度互补 |
| CU-20 | 关面板再开 | 回原位置 | 界面观察 |
| CU-21 | 重启界面 | 面板与宽度恢复 | 逐项比对 |
| CU-22 | 面板调自己方法 | 返回结果 | 面板显示 |
| CU-23 | 面板调 `kernel.shutdown` | 被拒，宿主未退出 | 进程仍在 + `E_UI_FORBIDDEN` |
| CU-24 | 面板内 `fetch` | 被浏览器拒绝 | 控制台报错 |
| CU-25 | 面板读外壳 `sessionStorage` | 抛安全错误 | 控制台报错 |
| CU-26 | 切暗色 | 一起变色 | 300 毫秒内 |
| CU-27 | 暗色下新开面板 | 首屏即暗色 | 录屏逐帧 |
| CU-28 | 停用带面板的插件 | 面板关闭并提示 | 界面观察 |
| CU-29 | 入口文件缺失 | 显示错误与「重试」 | 删文件后打开 |
| CU-30 | 请求 `../../plugin.toml` | 404 | 浏览器直接访问 |
| CU-31 | 无 token 请求 `/api/plugins` | 401 | 浏览器直接访问 |
| CU-32 | 四个面板 | 内存增量 ≤ 200 MB | 任务管理器 |

## 6. 本期明确不做的

远程访问与多用户、面板间自由互发消息、窗口自由拖拽与标签页、自定义主题颜色与第三方主题包、共享组件库、一插件多面板、面板级权限白名单、插件详情页、图表、国际化。
