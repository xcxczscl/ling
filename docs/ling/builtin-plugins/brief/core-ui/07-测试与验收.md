# core-ui 07 测试与验收

> 状态：初定 | 版本：1.1.0-b1 | 最后更新：2026-11-02
> 详细版：`docs/ling/builtin-plugins/core-ui/07-测试与验收.md`

## 1. 范围

### 1.1 测什么

服务端（路由、认证、路径检查、命名空间）、外壳（布局、导航、面板管理、设置页）、面板协议（七种消息、来源校验、超时并发）、安全（越权、跨源、穿越、注入）、稳定性（崩溃重启、故障隔离）。

### 1.2 不测什么

宿主内核行为、插件业务逻辑、浏览器兼容性矩阵、移动端。

## 2. 环境与方法

### 2.1 环境

Windows 10/11（desktop）；Edge 或 Chrome 111 起；每次用新数据目录 `run/t-<日期>-<序号>`；自写测试插件 `ui-demo`，方法 `echo`、`sleep`（40 秒）、`boom`（抛错）。

### 2.2 启动

```bash
ling serve --data-dir run/t-001
ling open
```

### 2.3 判据写法

只写可观察的事实，不写「正常」「正确」。

### 2.4 需求追溯

37 条 `CUI-REQ` 逐条挂用例，映射表在 `docs/ling/builtin-plugins/core-ui/07-测试与验收.md` §2.4，此处不重复。`SEC-05` 这类是威胁编号直接当用例编号用。`CU-32b`、`CU-32c`、`CU-15b` 是实现约束，不算需求。

## 5. 面板通信（C 组）

| 编号 | 步骤 | 期望 |
|---|---|---|
| CU-22 | 面板点 `echo` | 显示返回值 |
| CU-23 | 面板发 `kernel.shutdown` | 回 `E_UI_FORBIDDEN`，宿主仍在 |
| CU-24 | 面板内 `fetch("/api/plugins")` | 控制台报 CORS，无数据 |

CU-23 要跑三次：面板直发（外壳拒）、直接 `curl /api/panel/call`（服务端拒）、插件停用后调自己的方法（服务端拒）。

## 8. 性能与降级（F 组）

| 编号 | 步骤 | 期望 |
|---|---|---|
| CU-32 | 逐个打开 4 个面板，对比工作集 | 增量不超过 200 MB |
| CU-32b | 面板循环发 1000 条 `call` | 超 16 条的立即回 `E_UI_BUSY`，外壳不卡死 |
| CU-32c | 调 `sleep`（40 秒） | 35 秒收到 `E_TIMEOUT`，界面仍可操作 |
| CU-43 | 静态资源读超过 5 秒 | 回 504，界面显示「加载超时」 |
| CU-44 | 管理调用超过 30 秒 | 断开该次调用，其他请求不受影响 |
| CU-45 | 发一条 9 KB 的 `drag` | 回 `E_PAYLOAD_TOO_LARGE` |
| CU-46 | `params` 序列化 1.1 MB | 413，`E_PAYLOAD_TOO_LARGE` |
| CU-15b | 停用 `core-settings` | 界面可用，主题退化为亮色，配置页显示说明 |

## 9. 冒烟清单

起界面 → 开 `ui-demo` → 点 `echo` → 开第二个 → 关一个 → 切暗色 → 切回 → 插件页 → 日志页 → 越权调用 → 停用插件 → 重开界面。12 条全过再跑完整用例。

## 10. 验收出口条件

| 条件 | 判据 |
|---|---|
| 功能 | `CU-01` 至 `CU-32` 全过，无未修的 P0 |
| 安全 | §7 的 8 条全过，编码清单逐条勾完 |
| 文档 | `check_docs.py` 与 `check_refs.py` 无错误 |

P0 指：越权未被拦、token 出现在面板可读位置、路径穿越读到文件。任一条出现即不通过。
