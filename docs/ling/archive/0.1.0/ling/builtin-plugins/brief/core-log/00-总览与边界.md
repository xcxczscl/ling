# core-log 00 总览与边界

> 状态：已定稿 | 最后更新：2026-10-31
> 详细版：`docs/ling/builtin-plugins/core-log/00-总览与边界.md`

## 1. 一句话

把插件写出来的日志收拢到一处，按插件名与日期存成文件，并且能查。

## 2. 它解决什么问题

插件不该各自管日志文件，否则出问题时要翻五个目录、认五种时间格式。`core-log` 统一路径与行格式，与内核日志长得一样。

## 3. 它不做什么

不写内核日志（那是内核自己的事），不解析日志内容，不做轮转与清理，不做实时推送，不采集插件 `data/` 里的文件。

## 4. 与内核日志的关系

行格式相同、文件各写各的：内核写 `kernel-日期.log`，本插件写 `<插件名>-日期.log`。内核日志不能卸，本插件能卸。

## 5. 没装它的时候

插件调 `core-log.write` 得到 `E_PLUGIN_MISSING`；`ling logs <插件名>` 退回读插件 `data/` 下的 `.log`；宿主照常启动。这段退化由内核实现，不由本插件实现。

## 6. 谁在用

插件的写日志调用、命令行的 `ling logs <插件名>`，以后还有 `core-ui` 的日志面板。
