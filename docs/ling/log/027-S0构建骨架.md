## 二、撞到的一个真问题：`/utf-8`

第一次构建报了一串莫名其妙的错：

```
main.cpp(9): error C2143: 语法错误: 缺少";"(在"{"前面)
main.cpp(21): error C2039: "printf": 不是 "std" 的成员
```

原因不是代码写错，是 **MSVC 按本地代码页（GBK）读 UTF-8 源文件**。GBK 的双字节编码里，尾字节可能是
`0x5C`（反斜杠），而反斜杠在行尾表示「下一行续上」——于是中文注释把后面的代码一起吞了。

解法是在 `ling_set_standard` 里加 `/utf-8`，让源码与执行字符集都按 UTF-8 读。

这条要记住：**本项目所有源文件都带中文注释，缺 `/utf-8` 就会随机吞代码**。Linux 与 Clang 默认 UTF-8，
不受影响，所以这个问题只在 Windows 上、且只在注释恰好踩到 `0x5C` 时出现——属于「换了台机器就编不过」
的那一类。
