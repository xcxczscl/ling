# log 029 S2 上下文与效应账本

> 日期：2026-10-30
> 触发：S1 通过后继续

## 一、S2 判定与结果

| 项（`05` §5.1） | 结果 |
|---|---|
| 账本登记 | 方法注册时追加一条 `kMethodRegistered`，撤销动作是注销该方法 |
| 倒序撤销 | 停用与卸载都按倒序执行；撤销失败不中断后续 |
| 撤销失败的处理 | 卸载时若有失败，返回 `E_UNINSTALL_INCOMPLETE` 且**不删任何文件**，留现场 |
| 账本上限 | 10000 条，超限返回 `E_LEDGER_FULL`，并回滚刚注册的方法 |
| 数据目录 | `Context::data_dir()` 返回 `<数据根>/plugins/<编号>/data/`，构造时创建 |
| 账本外残留 | 撤销后仍残留在路由表里的方法，强制清空并记 warn |

## 二、顺带补的三个子命令

| 子命令 | 行为 | 依据 |
|---|---|---|
| `enable` | 从 `registry.json` 的 `disabled` 列表移除 | `LING-REQ-074` |
| `disable` | 加入 `disabled` 列表，下次启动不装载 | 同上 |
| `logs` | 打印当天内核日志末 40 行 | `LING-REQ-077` 的内核侧一半 |

`registry.json` 结构：`{"schema_version": 1, "disabled": ["..."]}`。解析失败时记 warn 并按空配置继续——配置坏了不该拦住启动（`09` §3.1）。

## 三、写的时候修的两个真问题

**① 重装被自己的判定挡住了。** `04/02` §2.1 规定「`plugin.toml` 存在即已安装；只剩 `data/` 的目录算未安装，可重装并沿用数据」。实现里早期写的是「目录存在就报 `E_PLUGIN_EXISTS`」，于是卸载后重装必然失败。改成按 `plugin.toml` 判定，并逐个顶层条目拷贝、跳过 `data/`。

**② 停用的插件在 `plugins` 里显示成「不存在」。** 因为装载表里没有它。已停用的插件确实装着，只是没加载，所以列表要单独扫一遍目录、标 `disabled`。

## 四、这一段的取舍

**账本按插件持有，暂不分代。** `04/03` §3 要求账本按「激活代」分段，避免反复停用激活撞上 10000 条上限。S2 每插件一个账本、停用即清空，等价于「每代一个」。等 S3 引入热更新与调和后再补分段。

**只建了两类效应。** 五类效应里目前只有「方法注册」会真正改变宿主状态；订阅、文件写、配置写、句柄这四类要等事件系统与 core-settings（S3、S6）才有落点。

## 五、距 MVP 还差什么

MVP 的定义是 `M1 + M2`（`11-MVP 范围.md` §2），当前状态：

| 能力 | 状态 |
|---|---|
| 装载与卸载（001 至 013） | 已实现，含数据保留与重装沿用 |
| 路由与事件（014 至 022） | 路由已实现；事件广播未做 |
| 能力门禁（023 至 027） | 注册时与调用时两处校验已实现 |
| 上下文与账本（028 至 038） | 账本与撤销已实现；订阅类方法未实现 |
| 管理端口与命令行（069 至 077） | 已有 install/uninstall/plugins/enable/disable/logs；缺 serve、shutdown |
| 内置插件（078 至 083） | 未做 |
| 性能与资源（089 至 099） | 未测 |

下一步按顺序：事件广播 → `serve`/`shutdown`（管理端口）→ 三个内置插件 → 验收脚本 `l1_manifest`、`l2_call` → 基准 `l1_bench_call`。

## 六、当前可复现的验证

```
ling install run/win-debug/plugins/demo-a      # 已安装
ling install run/win-debug/plugins/demo-caller # 输出 [demo-caller] reply=pong
ling plugins                                   # 两个都是 activated
ling disable demo-a                            # 下次启动跳过装载
ling uninstall demo-a                          # 只删安装工件，data/ 保留
ling install .../demo-a                        # 可重装，数据沿用
ling logs                                      # 打印当天内核日志
```
