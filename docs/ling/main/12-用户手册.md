# ling 12 用户手册

> 状态：已定稿 | 最后更新：2026-11-03
> 依据：`docs/ling/main/08-部署与发布.md` §4、§7；`docs/ling/main/04-详细设计/04-管理端口与命令行.md` §4、§5；`docs/ling/main/09-运行时预案.md`；`docs/ling/builtin-plugins/core-ui/`

本文是给**最终用户**的操作手册：怎么装、怎么启动、界面和命令怎么用、出问题怎么办。不涉及开发——写插件看 `docs/ling/plugin-support/`，改宿主看 `docs/ling/` 主体文档。

---

## 1. 安装

ling 是「解压即用」，不写注册表、不改 PATH、不装系统服务。

### 1.1 Windows

1. 解压 `ling-<版本>-win64.zip` 到任意目录，例如 `D:\apps\ling\`。
2. 在该目录打开终端，运行 `ling.exe serve`。
3. 首次运行自动初始化（装五个内置插件、生成配置），终端会打印数据根、端口、界面地址四行。
4. 浏览器打开 `http://127.0.0.1:8010` 进入界面。

也可以双击 `ling-<版本>-win64-setup.exe` 走安装向导，装到 `%LOCALAPPDATA%\Programs\ling`。

**不要解压到 `Program Files`**：宿主本身只读运行，但插件和日志写在数据根，放在受保护目录会让启动也要提权。

### 1.2 Linux

```bash
tar xzf ling-<版本>-linux-x64.tar.gz
cd ling-<版本>-linux-x64
./ling serve
```

或 `./install.sh` 装到 `~/.local/bin`（只建软链接，不需要 sudo）。

### 1.3 数据存在哪

数据根（插件、配置、日志）默认在 `%APPDATA%\ling`（Windows）或 `~/.local/share/ling`（Linux）。程序目录有 `ling.portable` 空文件时改为 `<程序目录>\data`（便携模式，数据跟程序走）。

## 2. 启动与停止

| 动作 | 命令 | 说明 |
|---|---|---|
| 启动 | `ling serve` | 前台运行，Ctrl+C 或关闭终端即退出 |
| 指定数据根 | `ling serve --data-dir <目录>` | 想用独立数据目录时加 |
| 打开界面 | `ling open` | 用默认浏览器打开界面地址 |
| 停止 | `ling shutdown` | 从另一个终端发停止信号 |

`serve` 会一直跑，不要关掉那个终端；日常操作在**另一个**终端用别的命令，或在浏览器界面里做。

## 3. 界面

界面是单页应用，左边导航、右边内容，六个页签：

| 页签 | 做什么 |
|---|---|
| 插件 | 看插件状态、装/卸/启/停 |
| 日志 | 看内核和插件的日志 |
| 配置 | 改配置（依赖 `core-settings` 插件，没启用时显示提示） |
| 任务 | 定时任务（依赖 `core-job` 插件） |
| 外观 | 改主题与界面显示 |
| 关于 | 看版本与许可信息 |

界面本身是 `core-ui` 插件提供的。卸掉 `core-ui` 界面就没了，但宿主的命令行照常可用。

## 4. 命令行速查

完整定义见 `docs/ling/main/04-详细设计/04-管理端口与命令行.md` §4、§5。

| 命令 | 作用 |
|---|---|
| `ling serve` | 启动宿主 |
| `ling shutdown` | 停止宿主 |
| `ling open` | 浏览器打开界面 |
| `ling plugins` | 列出插件及其状态 |
| `ling install <路径>` | 装一个插件 |
| `ling uninstall <插件名> [--purge]` | 卸一个插件；`--purge` 连数据一起删 |
| `ling enable <插件名>` / `ling disable <插件名>` | 启用 / 停用 |
| `ling reload <插件名>` | 换版本（重新装载产物） |
| `ling restart <插件名>` | 重启（停用再激活，不换产物） |
| `ling logs [插件名] [--kernel]` | 看日志；不带参数看内核日志 |
| `ling plan` | 预览一次装载/卸载会怎么变 |
| `ling job list / add / remove` | 定时任务（依赖 `core-job`） |
| `ling doctor` | 自检：依赖图环、未撤销条目、端口与口令文件、越权记录共四项 |
| `ling --version` / `--help` | 版本号 / 帮助 |

所有命令里「插件名」就是 `ling plugins` 第一列显示的那个值。

## 5. 常见问题

精编处置表；完整排查见 `docs/ling/main/09-运行时预案.md`。

| 现象 | 怎么办 |
|---|---|
| 命令行连不上宿主 | 两侧 `--data-dir` 是否一致；宿主是否还在跑 |
| 界面打不开 | 看 `registry.json` 的 `ui_port`；`ling plugins` 看 `core-ui` 是否启用 |
| 端口被占 | 管理端口自动顺延（7900–7999），界面端口自动选空闲 |
| 某个插件崩了 | 看 `ling plugins` 状态；进程内插件崩了宿主会隔离，侧车崩了 2 秒自动重启 |
| 想彻底删干净 | 先 `ling uninstall <插件名> --purge` 卸插件，再删数据根目录（见 `docs/ling/main/08-部署与发布.md` §7 手工清理清单） |
| 升级后行为不对 | 回滚到保留的上一版产物（`docs/ling/main/08-部署与发布.md` §6） |
| 数据根不可写 / 磁盘满 | 启动时宿主的四行输出会提示；换一个可写目录或清理磁盘 |
