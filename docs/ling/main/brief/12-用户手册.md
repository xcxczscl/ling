# ling 12 用户手册（简要版）

> 状态：已定稿 | 最后更新：2026-11-02

本文是 `docs/ling/main/12-用户手册.md` 的简要版。给最终用户：怎么装、怎么启动、界面和命令、出问题怎么办。

## 1. 安装

解压即用，不写注册表、不改 PATH。

### 1.1 Windows

解压 `ling-<版本>-win64.zip` → 目录打开终端 → `ling.exe serve` → 浏览器开 `http://127.0.0.1:8010`。或用 `setup.exe` 装到 `%LOCALAPPDATA%\Programs\ling`。

### 1.2 Linux

`tar xzf ...` → `./ling serve`，或 `./install.sh` 装到 `~/.local/bin`。

### 1.3 数据存在哪

默认 `%APPDATA%\ling`（Win）/ `~/.local/share/ling`（Linux）；程序目录有 `ling.portable` 时改为 `<程序目录>\data`。不要解压到 `Program Files`。

## 2. 启动与停止

| 动作 | 命令 |
|---|---|
| 启动 | `ling serve`（前台，Ctrl+C 退出） |
| 指定数据根 | `ling serve --data-dir <目录>` |
| 打开界面 | `ling open` |
| 停止 | `ling shutdown` |

## 3. 界面

五个视图：插件（装卸启停）、日志、配置（core-settings）、任务（core-job）、设置。界面是 `core-ui` 插件提供的，卸掉它界面就没了但命令行照常。

## 4. 命令行速查

`serve` 启动；`shutdown` 停止；`open` 开界面；`plugins` 列插件；`install <路径>` / `uninstall <名> [--purge]` 装卸；`enable` / `disable` 启停；`reload` 换版本；`restart` 重启；`logs [名] [--kernel]` 看日志；`plan` 预览变更；`job list/add/remove` 定时任务；`doctor` 自检；`--version` / `--help`。

## 5. 常见问题

| 现象 | 怎么办 |
|---|---|
| 命令行连不上 | 两侧 `--data-dir` 是否一致，宿主是否在跑 |
| 界面打不开 | 看 `registry.json` 的 `ui_port`；`ling plugins` 看 core-ui |
| 端口被占 | 自动顺延（管理 7900–7999，界面自动选空闲） |
| 插件崩了 | 进程内插件宿主隔离，侧车 2 秒自动重启 |
| 彻底删干净 | `uninstall --purge` 卸插件，再删数据根 |
| 升级异常 | 回滚到保留的上一版（见 `docs/ling/main/08-部署与发布.md` §6） |
